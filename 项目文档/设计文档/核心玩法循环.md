## 1. 经营深度

**采用中等经营深度**（已确定）。经营和防守同样重要，参考《They Are Billions》。

| 深度 | 参考 | 本项目 |
|---|---|---|
| 轻 | 《Warcraft III》：经营只为战斗服务 | 不采用 |
| **中** | 《They Are Billions》：资源、人口、维持消耗与防守并重 | **采用** |
| 重 | 《Banished》《RimWorld》：管理每个居民的需求 | 不采用 |

**核心矛盾：扩张与防守。**想发展就要向外扩张、占据更多资源；防线越拉越长，就需要更多士兵和防御塔；士兵和塔需要持续供养，又迫使玩家继续发展经济。

## 2. 玩法循环（设计提案）

```mermaid
flowchart LR
    A[开拓者采集资源] --> B[资源]
    B --> C[建造建筑]
    B --> D[招募士兵]
    C --> E[扩张领地]
    E --> A
    D --> F[抵御绿皮进攻]
    C --> F
    D -. 维持费 .-> B
    C -. 驻守建筑维持费 .-> B
    F -. 进攻逐渐增强 .-> E
```

1. **开拓者**采集资源、修建建筑。
2. **资源**用于建造、招募和供养。
3. **扩张**领地获得更多资源点，同时防线变长。
4. **士兵与驻守建筑**需要持续支付维持费。
5. **绿皮**定期进攻且逐渐增强，逼迫玩家发展。
6. **科技**由主角的知识解锁，推动时代从中世纪走向科技化。

## 3. 资源

**资源共 5 种**（已确定，暂定，后续可调整）：

| 资源 | 定位 | 主要用途（设计提案） |
|---|---|---|
| **人口** | 基础资源，由民居提供 | 产生金币；开拓者、士兵从人口中出 |
| **金币** | 通用货币，由人口产生 | 建造、招募、维持费 |
| **钢铁** | 材料 | 武器、坚固建筑、建筑升级 |
| **能源** | 供给 | 驱动灯光与科技建筑 |
| **魔晶** | 这个世界本土的魔法资源 | 科技建筑、科技兵种、高级升级；主角用它驱动科技造物，把魔法与科技连接起来 |

**人口产生金币**（已确定），与《They Are Billions》相同：**每名人口每分钟产出 9 金币**，被单位占用的人口不产出。

**击杀绿皮也获得金币**（已确定）：普通绿皮随机掉落 10–20 金币，作为经营收入的补充，见 [普通绿皮](敌人/普通绿皮.md)。

**钢铁来自[采矿场](建筑/采矿场.md)开采铁矿**（已确定），矿点在出生点附近刷出。能源、魔晶的来源待设计。

### 3.1 各资源与现有设计的联系（设计提案）

- **能源与塔灯**：[哨塔](建筑/哨塔.md)的塔灯可以消耗能源。能源不足时，塔灯变暗或熄灭，和黑夜、雨夜机制联动。
- **钢铁与升级线**：箭塔 → 弩塔 → 火炮塔的升级主要消耗钢铁，体现从木石到金属的时代推进。
- **魔晶与科技**：后期科技塔、科技兵种需要魔晶。

## 4. 人口

采用**民居产生人口**的方式（原方案 B，已确定），参考《They Are Billions》。民居共三级：木屋 10 人、瓦房 20 人、公寓 30 人，详见 [民居](建筑/民居.md)。主城提供 10 名初始人口，并生产开拓者。


- **规则层面**：人口是数字，按数字结算金币产出。
- **画面层面**：居民在民居和工作建筑之间走动，让基地更有生气；玩家不能控制居民。
- **实体单位**：开拓者、民兵是可操控的实体单位，从人口中出。

居民会不会被绿皮攻击、开拓者与士兵占用人口的数量，待设计。

## 5. 维持费

### 5.1 已确定规则

单位除了招募时一次性付费，存活期间还需要持续支付维持费，参考《They Are Billions》。这样不需要硬性的单位上限，玩家会自己在经济和兵力之间找平衡。

1. **维持费扣金币**，相当于军饷。原先设想消耗食物，资源调整后改为金币。
2. **单位占用人口**：开拓者、士兵从人口中出，被占用的人口不再产生金币。造兵的代价是收入减少，维持费增加。
3. **高级兵种额外占用其他资源**：越强的兵种还要占用钢铁、能源、魔晶等，越贵也越难养。
4. **驻守建筑不占用人口**：箭塔、哨塔只支付维持费，不占用人口，避免规则过于复杂。

**不设维持费的问题：**招募只花一次钱，后期兵力会无限膨胀，经营失去压力，同屏单位过多也影响性能和画面。

### 5.2 设计提案

- **维持费对象按「是否有人驻守」判断**，保持逻辑一致：

| 对象 | 维持费 | 理由 |
|---|---|---|
| [民兵](单位/民兵.md) | 5 金币 / 分钟 | |
| [开拓者](单位/开拓者.md) | 3 金币 / 分钟 | 降低开局压力 |
| [哨塔](建筑/哨塔.md) | 5 金币 / 分钟 | 有哨兵驻守 |
| [箭塔](建筑/箭塔.md) | 10 金币 / 分钟 | 有弓箭手驻守，人数较多 |
| [民居](建筑/民居.md) | 无（已确定） | 居民不是单位，只代表金币产出 |
| [兵营](建筑/兵营.md)、[主城](建筑/主城设计.md)、[城墙](建筑/城墙.md) | 无 | 无人驻守或属于基础设施 |

- **入不敷出时采用温和惩罚**，避免「缺钱 → 变弱 → 失地 → 更缺钱」的死亡螺旋。收支恢复后立即恢复：

| 对象 | 效果 |
|---|---|
| 士兵 | 攻击力下降（如 −30%），不会消失 |
| 哨塔 | 视野缩小 |
| 箭塔 | 攻击间隔变长 |
| 开拓者 | 建造速度变慢 |

以上金额已确定，所有价格见 [成本体系](系统/成本体系.md)。
