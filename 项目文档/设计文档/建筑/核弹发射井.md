## 1. 建筑定位

核弹发射井是**科技体系的 3 本建筑**（研究院升到 3 本后解锁），是玩家手里的「大招」：平时自动装填核弹，攒满后由**玩家手动释放**，炸平一片区域。

**名称：**核弹发射井（已确定）。**主动技能：发射天火**（已确定），即释放核弹。

## 3. 核弹规则

| 规则 | 内容 | 状态 |
|---|---|---|
| 释放方式 | 主动技能「**发射天火**」：玩家手动指定目标位置 | 已确定 |
| 装填 | 每 **180 秒**造好 1 枚，最多储存 **1 枚** | 设计提案 |
| 装填费用 | 每枚 **200 钢铁**，装填完成时扣除 | 设计提案 |
| 目标范围 | 任意已探索过的区域，不受射程限制 | 设计提案 |
| 预警 | 落地前 **5 秒**，目标地面出现红圈，敌我都能看到 | 设计提案 |
| 爆炸范围 | 半径 **15 m** | 设计提案 |
| 伤害 | 中心 **1000**，向外线性降低，边缘 **300**；物理伤害 | 设计提案 |
| 误伤 | **我方单位同样受伤；我方建筑受一半伤害** | 已确定 |

**误伤的用意：**核弹不能无脑砸在自家防线上。玩家要先撤兵，或等绿皮冲到防线前方再释放，形成真正的取舍。

## 4. 深坑（已确定）

**核弹爆炸后在地面留下深坑，任何单位都不能通过；过一段时间后深坑自行恢复。**

| 规则 | 提案值 |
|---|---|
| 深坑范围 | 爆炸中心半径 **8 m** |
| 持续时间 | **90 秒**后恢复为平地 |
| 通行 | 敌我单位都不能进入，需要绕行 |
| 建造 | 深坑内不能建造 |
| 已有建筑 | 有建筑占据的地面不形成深坑，建筑按误伤规则受伤后原地保留 |
| 坑内单位 | 爆炸时位于深坑范围内、没被炸死的单位，被推到深坑边缘 |

**战术用途：**深坑是一道临时的「墙」。在绿皮进攻路线上炸出深坑，除了杀伤，还能迫使后续的绿皮绕路 90 秒，为防线争取时间。

## 5. 强度检验

普通绿皮属性以设计提案为准：**200 生命、20 攻击、1.5 秒攻击间隔、无护甲、近战、移动速度 3 m/s**。

| 位置 | 结果 |
|---|---|
| 距中心 0–15 m 内的普通绿皮 | 受 300–1000 伤害，全部消灭 |
| 同范围内的[破咒小子](../敌人/破咒小子.md)（300 生命、护甲 10） | 边缘受约 225 实际伤害，存活；距中心约 11 m 以内被消灭 |
| 我方民兵（150 生命）在范围内 | 全部阵亡 |
