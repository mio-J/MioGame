## 1. 建筑定位

造船厂是**生产船只的建筑**（已确定），可以造两种船：

| 船 | 用途 |
|---|---|
| [运输舰](../单位/运输舰.md) | 把人送到船上，载着移动到别的大陆 |
| [曙光号](../单位/曙光号.md) | 像[曙光](曙光.md)一样发射大激光，靠海水散热射得更久，伤害更低 |

世界是 2048 米的一整块星球，海上有隔开的大陆和岛屿（见[地图与资源点](../系统/地图与资源点.md)）。陆地上的单位过不去，造船厂是**唯一跨海的手段**。

## 3. 生产规则（设计提案）

| 规则 | 内容 |
|---|---|
| 队列 | 最多 **3** 个，依次建造（船比步兵贵，队列更短） |
| 集结点 | 可设置，新船下水后自动前往（必须是水面上的位置） |
| 取消 | 可以，全额返还 |
| 多座造船厂 | 允许，以加快出船；每座必须临海 |
| 运输舰 | 科技 2 本即可建造 |
| 曙光号 | 需要魔法 3 本 + 科技 3 本，即和[曙光](曙光.md)同样的门槛 |

## 4. 船只的通用规则（设计提案）

- 船只只能在水面上行驶，不能上岸。
- 船只按海水深度分档：**运输舰**可以在浅海和深海行驶；小船不能进入河流和湖泊，除非水体足够大（待定）。
- 靠岸方式：船开到岸边，陆地单位可以上船或下船，无需码头。
- 船只可以被敌人攻击，但敌人目前多是陆地单位，远程绿皮（射程 9 m）也只能打到贴岸的船。
