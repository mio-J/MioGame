## 1. 建筑定位

传送阵是**远距离传送的设施**：**单位走进传送阵，就会被传送到另一座传送阵**（已确定）。它把相隔很远的两处连成一条「一步就到」的通道，玩家不再需要花几分钟让单位走完 2048 米世界里的长路。

它主要解决两件事：
- **远处的矿区、据点补给和增援：**世界很大，远处的矿点离主城几百上千米，传送阵让军队和开拓者可以瞬间抵达。
- **拉长防线后的机动：**扩张让防线变长，传送阵让有限的兵力能快速支援不同方向。

**归属（设计提案）：**魔法体系，法师营地升到 3 本后解锁。传送是魔法造物，也让魔法路线在移动上有独特价值。

## 2. 传送规则

| 规则 | 内容 | 状态 |
|---|---|---|
| 传送方式 | 友方单位走进传送阵，被传送到与它连接的另一座传送阵旁边 | 已确定 |
| 传送对象 | 友方单位；敌方单位**不会**被传送，也不能使用 | 设计提案 |
| 触发 | 单位走进传送阵的入口范围即触发，不需要额外操作；玩家也可以对传送阵右键，让选中的单位走进去 | 设计提案 |
| 传送距离 | **不限制**，只要两座传送阵都在世界内 | 设计提案 |
| 传送时间 | 单位进入后经过 **1 秒**的过渡，在另一端出现 | 设计提案 |
| 数量 | 一次可以传送多个单位，没有人数上限 | 设计提案 |
| 陆地限制 | 传送阵必须建在陆地上；两座传送阵**可以分处不同大陆**，传送时直接越过海洋 | 已确定 |
| 建立第一条跨海通道 | 要在另一块大陆上建传送阵，得先用[运输舰](../单位/运输舰.md)把开拓者送过去，所以造船厂仍然是跨海的第一步，传送阵是之后的快速通道 | 设计提案 |

## 3. 连接方式（设计提案）

| 规则 | 内容 |
|---|---|
| 成对连接 | 一座传送阵只与**另一座**连接，两座为一组 |
| 建造 | 每座传送阵独立建造；建成后，玩家选中一座传送阵，再选另一座，点击「连接」建立通道 |
| 重连 | 可以随时断开并重新连接到别的传送阵，重新连接有 **10 秒**的冷却 |
| 单向 | 通道是**双向**的，走进哪端就从另一端出来 |
| 一端被摧毁 | 通道立即中断，另一端保留但不再工作；重新建一座并连接即可 |
| 单独存在 | 没有连接对象时，传送阵只是一座静态建筑，走进去没有效果 |

## 5. 强度与风险

| 项目 | 结果 |
|---|---|
| 一组传送阵占用能源 | 200，相当于半个高本数的塔，不能无限铺设 |
| 敌人是否可以借道 | 不可以，敌人无法使用传送阵，所以它不会被当成敌人的捷径 |
| 一端被拆 | 通道断掉，因此远端的传送阵需要保护，例如配合隐形哨塔盯住 |

**设计意图：**
- 传送阵让世界的「大」变得可以驾驭，但它有能源成本，不会满地都是。
- 远端的传送阵是弱点：一旦被敌人拆掉，远征队就被隔在外面。
- 传送阵**可以连接不同大陆**（已确定）：第一次到达别的大陆仍需要[造船厂](造船厂.md)的运输舰把开拓者送过去、在那里建好传送阵；此后两块大陆之间就是一步之遥，运输舰不必反复往返。
