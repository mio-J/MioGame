# 单位强度视觉分层提案

日期：2026-09-30。状态：讨论提案，尚未采纳为全体单位的制作规范。本次仅按用户反馈修改骑士、绿皮弓手、破咒小子的概念图；其余单位未重画，玩法与数值未修改。

## 1. 先把两个“本数”分开

现有规则同时包含科技阶段和生产建筑自身等级，不能直接给所有角色贴同一种“一本／三本”标签。

| 维度 | 现有例子 | 建议如何表达 |
|---|---|---|
| 科技路线门槛 | 圣堂需要魔法 2 本；星象殿需要魔法 3 本 | 招募界面写明前置；兵种外观表现基础、专业、高阶的差异 |
| 生产建筑等级 | 骑士需要兵营 3 本；同种民兵也能由不同等级兵营招募 | 局部装备变化，加上选中面板的明确等级标记 |
| 职能与克制 | 牧师治疗、骑士追击、破咒小子魔免 | 武器、轮廓、特征符号优先，不能用同一套大盔甲覆盖所有职业 |

依据：[科技系统](../../../系统/科技系统.md)、[兵营](../../../建筑/兵营.md)、[圣堂](../../../建筑/圣堂.md)、[星象殿](../../../建筑/星象殿.md)。建筑升本只强化之后招募的单位，已有单位保持原属性；视觉标记也应保留其招募时的等级，不能随建筑升级让全军同时换装。

## 2. 用三个视觉档次表达投入与专业程度

以下是美术档次，不额外规定任何单位的解锁条件，也不代表所有高阶单位都能在单挑中胜过低阶单位。

| 美术档次 | 远看轮廓 | 近看装备 | 特效 |
|---|---|---|---|
| 基础 | 简单、窄小，主武器一眼能认出 | 粗布、木制品、少量铁件，结构朴素 | 通常无常驻特效 |
| 专业 | 职业特征完整，武器或护具形成清楚的第二轮廓 | 配套装备、明确防护部位、加工更精细 | 局部、短时，服务技能辨识 |
| 高阶 | 有一个强记忆点，例如人马甲块、宽肩礼服或大型法器 | 更完整的结构、更明确的材质分区，少量高规格部件 | 克制且独有，优先在施法时表现 |

**优先级：轮廓 → 主装备 → 材质分区 → 装饰。**俯视游戏里细小金边、胸针、指环很难看见，不适合独自承担强度辨识。阵营配色应跨档次保持一致；颜色只能辅助，不能成为唯一等级标记。人体大小不必随本数增长。

## 3. 落到当前单位

| 单位 | 当前门槛／定位 | 建议的区分方式 |
|---|---|---|
| 民兵 | 兵营基础单位 | 长矛、木盾、粗布，维持基础轮廓；高等级版本也保留民兵身份 |
| 火枪手 | 兵营额外解锁；科技本数前置待定 | 火枪与弹药装具表现专业化；不擅自归为科技 2 本 |
| 牧师 | 圣堂招募，圣堂需魔法 2 本 | 紧凑袍服、简单法杖，治疗识别优先 |
| 圣堂刺客 | 圣堂额外解锁，额外前置待定 | 紧身轻装、双刃、前倾姿态；强度来自突击感，不增加重甲 |
| 圣骑士 | 科技 2 本并需解锁；圣堂招募仍为提案 | 步行重甲、盾锤、少量现代部件，强调站稳防线 |
| 骑士 | 兵营 3 本自动解锁 | 采用本次人马重甲提案，与民兵、步行圣骑士拉开轮廓；厚重同时保留机动感 |
| 法师 | 圣堂 3 本、法师营地 3 本并额外解锁 | 高规格施法器、清晰法衣结构、独有施法姿态；不靠更厚护甲表示输出强 |
| 星象殿四类单位 | 招募建筑需要魔法 3 本；星象殿自身等级独立 | 保留环杖、星盘、成对护臂、星术法器等各自主特征，以装备结构体现高阶来源 |

例如牧师与大主教可以通过“简洁直线袍服＋简单杖头”和“较宽仪式轮廓＋圆环杖头”区分；这是提案，不代表给牧师增加攻击或给大主教增加护甲。

## 4. 同兵种升本只作局部变化

建议固定武器种类、基本体形和阵营色，以共用模型加部件控制制作成本：

| 招募时生产建筑等级 | 同兵种外观提案 | 界面辅助提案 |
|---|---|---|
| 1 本 | 原始基础装备 | 名称旁 I |
| 2 本 | 增加一处明显的实用加固，例如盾缘包铁、前臂护具 | 名称旁 II |
| 3 本 | 更完整但不夸张的加固，再加一处统一肩部标记或短披肩 | 名称旁 III |

这套变体仅适用于实际能在对应等级招募的单位。骑士本来就要求兵营 3 本，无需凭空制作“1 本骑士”。面板建议写“招募来源：兵营 Lv.3”，避免和“科技 3 本”混淆；有需要时再显示科技前置。

## 5. 敌人按威胁类型辨识

- **绿皮弓手：**瘦削驼背、粗木弓、破布、简陋箭筒，传达脆弱的后排杂兵；不采用英俊游侠或精锐猎人的服饰。
- **破咒小子：**裸露皮肤上的大块暗色符文、低头斜视、佝偻身形、压低的微光，传达异常和魔免。保留近战武器，避免误读成远程法师。
- 敌人目前没有玩家式的一至三本招募体系，不直接给它们套兵营等级。
- 破咒小子原文的高生命值、护甲数值仍为玩法提案。裸肤符文可以作为超常耐受的视觉解释，但不新增机制；若未来认为高物理护甲与形象不符，再单独讨论数值。

## 6. 后续验证标准

制作游戏内模型时，将同批单位放在相同地面、光照与实际俯视镜头下检查：缩小后能否认出兵种，关闭特效后能否区分基础与高阶，转为灰度后是否仍能辨识。避免让所有单位变得更大、更亮、更华丽。当前完成的是概念图审阅，尚未完成游戏内验证。
