## 1. 适用范围

适用于所有建筑的**建造**和**修理**。执行者都是[开拓者](../单位/开拓者.md)，玩家不需要手动选中某个开拓者，而是由系统**召集最近的开拓者**前去。

## 2. 召集最近的开拓者（已确定）

**建造和修理使用同一套召集规则：**

- 每个建筑都有一个「**修理**」选项。放置新建筑时，也会自动发起建造。
- 发起后，系统召集**离目标建筑最近的开拓者**前去执行。
- **附近没有开拓者时，界面给出提示**，本次操作不生效。

### 2.1 召集细节（设计提案）

| 规则 | 内容 |
|---|---|
| 召集范围 | 以目标建筑为中心 **60 m** 内的开拓者才会被召集 |
| 选择顺序 | 召集范围内**最近的空闲开拓者**（没有在建造或修理的） |
| 全都在忙 | 范围内的开拓者都在忙时，同样给出提示「附近的开拓者都在忙」，本次操作不生效；**没有排队机制** |
| 距离判断 | 按实际行走距离，而不是直线距离 |
| 提示内容 | 范围内没有开拓者：「附近没有开拓者」 |
| 任务中断 | 开拓者在赶去的途中阵亡，任务回到待分配状态，重新召集 |
| 玩家手动指派 | 玩家也可以手动选中开拓者，直接下令去建造或修理，优先于自动召集 |

不设排队是为了保持规则简单：玩家发起操作时就知道有没有人去，不会出现「任务挂着很久没人管」的情况。

### 2.2 光圈反馈（已确定）

为了让玩家一眼看出「谁被叫去干活了」，开拓者脚下会出现光圈，颜色表示命令的来源：

| 颜色 | 含义 | 状态 |
|---|---|---|
| **蓝色光圈** | 开拓者收到了**系统召集**（建造或修理），正在前往或执行任务 | 已确定 |
| **绿色光圈** | 玩家**自己选中**并下达移动命令的单位 | 已确定 |

**虚线（已确定）：**被召集的开拓者与目标工地之间会有一条**虚线**，颜色很淡，用来指示他要去哪里。**只有选中该工地（或修理的目标建筑）时才显示**，没选中时不显示，避免同时召集多人时屏幕上线条太乱。

规则细节（设计提案）：

| 规则 | 内容 |
|---|---|
| 虚线颜色 | 与蓝色光圈同色系，透明度很低，不抢眼 |
| 虚线起止 | 起点是开拓者脚下，终点是目标建筑或工地 |
| 虚线显示 | 仅在玩家选中该工地或目标建筑时显示，取消选中即隐藏 |
| 虚线消失 | 开拓者到达并开始施工后消失；任务被取消时同时消失 |
| 蓝色光圈出现 | 玩家发起建造或修理，系统召集到开拓者的那一刻，被召集的开拓者脚下立即出现 |
| 蓝色光圈消失 | 任务完成或被取消（包括玩家手动接管这名开拓者）后消失 |
| 绿色光圈 | 玩家选中单位时显示；下令移动后保持，到达目的地或取消选中后消失。所有玩家选中的单位共用这个颜色，不限于开拓者 |
| 两种同时存在 | 玩家选中了一名正被召集的开拓者时，脚下显示**绿色**（选中优先），同时保留一个小的蓝色标记表示他仍有召集任务 |
| 赶路时手动接管（已确定） | 开拓者在赶去工地的**途中**，玩家手动控制他（下达移动等命令），就**取消这次建造 / 修理**：蓝色光圈与虚线消失，已扣的建造费用全额返还，工地取消；**不会自动召集别的开拓者接手** |
| 只选中不算接管 | 只是选中开拓者、没有下达命令，不算接管，任务继续；下达移动、攻击等命令才算 |
| 取消提示 | 取消时显示简短提示，例如「建造已取消，费用已返还」，避免玩家不知道发生了什么 |
| 施工中不能接管 | 开拓者开始施工后不能被移动，玩家的移动命令无效并提示「开拓者正在施工」；想让他离开，只能取消这个工地（已开工取消返还 50%），见「建造」一节 |
| 附近没有开拓者，或都在忙 | 不会出现任何光圈，只显示「附近没有开拓者」或「附近的开拓者都在忙」的提示 |

## 3. 建造

| 规则 | 内容 |
|---|---|
| 发起 | 在选定位置放置建筑，立即产生一个**建造工地** |
| 扣费 | 放置时一次性扣除全部成本，取消建造时全额返还，见[成本体系](成本体系.md) |
| 施工 | 被召集的开拓者到达工地后开始施工，时间见各建筑的「建造时间」（按 1 名开拓者计） |
| **施工时不能移动（已确定）** | 开拓者一旦开始施工就**不能被移动**，玩家下达的移动等命令会被忽略，并提示「开拓者正在施工」。这样就没有「中途被拉走、进度暂停、还要再补一次」的麻烦，规则也更简单 |
| 施工期间 | 建筑不能使用；开拓者施工时不能移动，且是无敌的；工地可以被攻击，工地被摧毁时开拓者死亡，生命值与被摧毁规则见 3.1 节 |
| 取消 | 开拓者还在赶路、尚未开工时取消，**全额返还**；已经开工后取消，返还**已付费用的 50%**（与被摧毁相同，避免玩家在工地将被摧毁前取消来拿全额），开拓者随即解除施工状态，恢复可控 |

### 3.1 施工期间被袭击（设计提案）

| 问题 | 提案 |
|---|---|
| 工地能被攻击吗 | **能。**工地和已建成的建筑一样是敌人的目标，遇墙就近拆墙等规则同样适用 |
| 工地的生命值 | 随施工进度增长：**当前上限 = 最大生命值 × （20% + 80% × 进度）**。刚开工只有 20%，完工时 100% |
| 已受的伤害 | 伤害是累计的，进度增长带来的生命值增加不会「抹掉」已受的伤害：受损后继续施工，生命值按上限的增长量同步增加，伤害仍然存在 |
| 护甲 | 与建成后相同，不因施工而降低 |
| 被摧毁 | 工地生命值降到 0 时被摧毁，工地消失，**返还已付费用的 50%**（与拆除已建成建筑的返还一致，见[成本体系](成本体系.md)），**施工中的开拓者随之死亡**（已确定，见下一行） |
| 开拓者（已确定） | **施工中的开拓者是无敌的**：敌人和范围伤害都打不到他，敌人只能攻击施工中的建筑物；但**建筑物被摧毁时，开拓者才会被杀死**。他也不能被玩家移动，只能继续施工 |
| 救他的办法 | 工地快撑不住时，只能**取消工地**（返还 50%），开拓者随即恢复可控，或者用其他单位、塔去保护工地 |
| 赶路途中 | 尚未开工、还在赶去工地的开拓者**不无敌**，会像普通单位一样被攻击 |
| 工地作用 | 施工中的塔不能攻击，民居不产出，城墙段作为障碍仍然存在，可以挡住敌人，也会被敌人拆 |
| 预警 | 工地遭到攻击时，与已建成建筑一样触发预警提示 |

**示例：**箭塔（300 生命、建造 20 秒）刚开工时只有 60 点生命值，一只普通绿皮 4 次命中就能拆掉；建到一半有 180 点；快完工时接近 300。所以**在敌人来袭前一段时间不要在前线开工**，先把塔建在后方安全的位置。

**代价：**工地被摧毁不仅损失一半费用，还会损失一名开拓者（50 金币、15 秒重新生产，并占用人口）。开拓者是无敌的，但他和工地绑在一起，这让「在哪儿开工」成为有实际后果的选择。

**为什么这么设计：**
- 施工有风险，玩家会更谨慎地选择开工时机，塔和墙的布防更有策略，而不是随时随地"补塔"。
- 前期建造时间只有 15–30 秒，暴露窗口短，不至于让施工变成陷阱。
- 返还 50% 而不是全部损失，避免开局 150 金币的时候一次失误就无法翻身，同时保留惩罚。

**只能 1 名开拓者建造（已确定）：**每处工地同时只有 1 名开拓者施工，不支持多人协作加速。想同时建更多建筑，就需要更多开拓者分头去建。这也让开拓者的数量成为一项实实在在的投入。

## 4. 修理

### 4.1 修理选项

- 选中任何**已建成且受损**的建筑，都有「修理」按钮；生命值已满时按钮置灰。
- 施工中的建筑不能修理。
- 修理由玩家主动点击触发，不会自动修理（设计提案）。

### 4.2 修理的表现与计算（已确定）

**修理看起来就是回血：开拓者到场后，建筑的生命值开始逐渐恢复，恢复的同时持续扣除金币。**修理的时间和金币，都按**生命值缺口**的比例计算。

- **只能 1 名开拓者修理**，不支持多人协作。
- 缺口越大，花的时间越长，花的金币越多；缺口为零则不用修。
- 修理过程中金币是**逐步扣除**的，不是开始时一次收清；玩家可以看到金币随着血量一起变化。

### 4.3 费用与速度数值（设计提案）

| 项目 | 规则 |
|---|---|
| 费用 | 生命值缺口 100% 时，费用 = 该建筑**建造成本的 50%**；缺口不足时按比例折算 |
| 速度 | 缺口 100% 时，1 名开拓者修满 = 该建筑**建造时间的一半**；缺口不足时按比例折算 |
| 回血速率 | 每秒恢复的生命值 = 生命值上限 ÷（建造时间的一半），全程匀速 |
| 金币不足 | 修理暂停，金币够了继续 |
| 只用金币 | 修理只消耗金币，不消耗钢铁等材料 |
| 战斗中 | 可以修理。开拓者不参与战斗，前线修理有被攻击的风险 |

**为什么是 50%：**与[成本体系](成本体系.md)中拆除返还 50% 的规则一致，拆掉再重建总是比修理更贵，不会让「拆了重建」成为最优。

**示例：**

| 建筑 | 成本 | 修满费用 | 修满时间 |
|---|---|---|---|
| 箭塔 | 120 | 60（缺一半血则 30） | 10 秒（缺一半则 5 秒） |
| 城墙（每段） | 50 | 25 | 15 秒 |
| 兵营 | 150 | 75 | 15 秒 |

### 4.4 主城的修理

主城没有建造成本，无法按成本比例计算。提案：每修复 **100 点**生命值花费 **20 金币**，修满 2000 点约 400 金币；1 名开拓者修满需要 **120 秒**（每秒恢复约 17 点）。主城血量已提高到 2000（见[主城设计](../建筑/主城设计.md)），修理速度和费用之后需要一起复核。

### 4.5 作为金币消耗口

修理费用随建筑规模增加，防线越长、受损越频繁，花费越多。这让金币在后期仍有用处，见[核心玩法循环](../核心玩法循环.md)中关于金币通胀的讨论。
