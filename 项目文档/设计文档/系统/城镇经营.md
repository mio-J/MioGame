## 1. 问题

现在的经营基本是一条线：造民居 → 人口自动产金币 → 金币用于造塔、招兵、付维持费。玩家在经营上能做的决定很少；邻里效应、踩出来的路都在后台起作用，玩家感觉不到。

## 2. 已确定（2026-10-07）

1. 采用四项：**建筑组合、城镇等级、商店街、小反馈（飘字等）**。
2. **城镇等级只解锁[〔经营建筑〕](标签.md#经营建筑)**（民居、商店、装饰、组合等），塔仍由升本解锁。两条线：
   - 本数管打仗；
   - 城镇等级管过日子。
   - 建筑分两大类（2026-10-08）：赚钱用的 [〔经营建筑〕](标签.md#经营建筑)、打仗用的 [〔军事建筑〕](标签.md#军事建筑)，建造栏分两页，见[标签](标签.md)。
3. **科技升本门槛**由「总人口」改为「城镇等级」。魔法看英雄等级，科技看城镇等级。
4. **瓦房、公寓**由城镇等级解锁。
5. **电影院、市政厅**由研究院 2 本 / 3 本改为城镇等级解锁，研究院只管打仗。

以上第 3–5 条已同步写入[科技系统](科技系统.md)、[民居](../建筑/经营建筑/民居.md)、[电影院](../建筑/经营建筑/电影院.md)、[市政厅](../建筑/经营建筑/市政厅.md)。

## 3. 人口与金币（叠加，不改原规则）

民居照常赚钱：每名人口每分钟 180 金币，这条已确定的规则不变。商店是额外收入，叠加在上面。

人口的用处：

| 用处 | 说明 |
|---|---|
| 交税 | 每人每分钟 180 金，基础收入 |
| 出兵 | 开拓者、士兵从人口中出，被占用的人不交税 |
| 当顾客 | 商店的生意来自附近居民（及上下班路过的人流），附近人越多，商店赚得越多 |
| 繁荣度 | 人口是繁荣度的大头，决定城镇等级 |

## 4. 城镇等级

### 4.1 繁荣度

繁荣度是一个数，攒够了城镇就升一级。它按「现在有多少」计算，不是累计值，所以会涨也会跌；**城镇等级只升不降**。

| 来源 | 怎么算（样例，待定） | 大致占比 |
|---|---|---|
| 人口 | 每 1 名**已入住**居民 1 点；去当兵、当开拓者的人也算（不然招兵会掉繁荣度） | 约 60% |
| 组合 | 每个成立的组合按档次给 5 / 10 / 20 点；同一种组合第 2 次给一半，第 3 次起给四分之一，最多算 5 次 | 约 20% |
| 商店 | 按城里商店的**种类数**计，不按座数；每种 8 点 | 约 15% |
| 公共建筑 | 电影院 +10、市政厅 +20、地标（[主角雕像](../建筑/经营建筑/主角雕像.md)）+30 | 约 5% |

- 装饰首版不让玩家手摆（操作量太大），自动长出来的装饰不算分。
- 建筑被拆时，它提供的繁荣度立刻扣掉，原地冒灰色「−繁荣 X」。繁荣度跌到当前等级线以下没有惩罚，只是进度条变灰。
- 界面只强调两件事：**人口最重要**；**凑新组合、开新种类的店能冲一截**。递减规则不用讲，玩家第二次只看到小数字就懂了。
- 显示：资源栏旁的城镇徽章和进度条；鼠标悬停显示各来源明细和「下一级解锁」。

## 5. 商店

### 5.1 通用规则（只用一套「消费池」公式）

| 规则 | 内容（数值待定） |
|---|---|
| 消费池 | 每名空闲已入住的居民，每分钟最多带来约 **30–40 金**生意。每名空闲居民只算一次；单位与招募预留人口不当顾客 |
| 分给谁 | 居民的这份钱，花在他家附近约 15 m 内的不同种类商店。每种店有自己的**客单**（每人每分钟在这种店花多少，见各商店文档）；附近各种店的客单加起来超过上限时按比例缩小，客单相同时就是平分。一片街区开 2–3 种店最赚，再多只是分钱（客单规则为 2026-10-08 设计提案） |
| 同种店 | 同种店服务范围重叠时，平分顾客 |
| 上限 | 商店收入和民居的各种加成一起，计入[城市形成](城市形成.md)的总加成上限（+100%），避免金币通胀、架空电影院 |
| 玩家看到的 | 显示**店铺星级**（★1–★3），公式藏在后面；建造预览同时显示「本店生意 / 全城净收入变化」，含被分走的旧店收益、工业噪音、能源与维护；允许0/负数并明确饱和提示。星级暂按每分钟生意划分：600 金以下 ★1，600–1599 金 ★2，1600 金及以上 ★3（设计提案） |
| 人口、维持费 | 不占人口；低级店没有维持费，高级科技店占用能源 |
| 占地、价格 | 3 × 3 m；同种店价格逐座递增；具体价格待定 |
| 道路、路人 | 门前道路倍率和路过人流放到「踩出来的路」做好之后再加，首版不做 |
| 附加作用 | 两种：① 招募时加成（只给之后招的兵）；② 店附近的范围光环。同种店的附加作用不叠加 |
| 招募时加成 | **每个兵最多带 1 项**（护甲、药水、护盾），生产建筑可预设可用护甲、药水或护盾中的一项，不强制覆盖；护甲基础+3/军械所+5/招兵买马+5或+7同源取最大、最高+7，不相加；单位面板显示「新兵已带：药水」 |
| 魔晶 | 没有产魔晶的店，维持「魔晶来自打怪/营地及既有炼金应急兑换」 |

界面上把消费池写成「每名居民最多带来 X 金生意」，不叫「零花钱」，免得玩家以为钱是从税里扣的。

### 5.1.1 唯一结算公式（原型测试基线）

税收、消费与招募共用同一房屋人口记录。总空闲人口 `F=max(0,min(已入住总数,当前容量)−单位占用−招募预留)`；被拆房的闲居民移出不产税/生意，单位不凭空消失，超容量时停止新入住/招募。分配到住宅的占用记录稳定，不能为了多享受光环而每帧换房。

对每个空闲居民，设所在住宅税收加成B（所有有效同类取强、异类相加，旧邻里与住宅组合不重复），税收 `T=180×clamp(1+B,0.7,2)`；普通潜在消费池 `C=(40+10×在雕像范围内)×K`，凯旋60秒K=2，其余K=1。税收和商业共享每居民180基础的+100%增益空间，实际消费上限 `C_eff=min(C,max(0,360−T))`。

每种有效店只计算一份客单w（夜间酒馆/旅馆、百货×1.25、不夜城权重、凯旋×2先作用于w）；`q_i=w_i×min(1,C_eff/Σw_i)`，同种多店重叠再平分q_i。不夜城不另翻消费池，公共税收增益不再乘商店收入。邻里负收益不应凭空增加普通消费池，仍有C限制。

例如40居民面包+杂货960/分；夜间再加酒馆达1600/分；再开电器行仍1600，只分走旧店收入。电影院30%+市政厅45%+大杂院10%共85%，税333，商业仅剩27；雕像50不能无视上限。主城区选税、外围商业区选消费是布局取舍；放置预览解释具体限制。

账本按秒或固定经济tick累计真实数额，最终收益不逐店取整。展示可取整并合并，尾数继续累计，绝不「至少+1」凭空发币。三星仍600/1600实际营业额阈值，百货不虚增显示星级。

等级只升不降、不新增30秒稳定等待。繁荣按当前人口、有效店种、合法组合和公共建筑计；拆建冲级仍有成本并列入试玩专项检查。每建筑最多2组合，核心建成顺序分配、重复5/10/20档第2次半分/第3–5次四分之一。特大中心城区统一30分；住宅小村落税+5%/大杂院+10%，同一成员大杂院取代小村落不重复。

## 6. 建筑组合

### 6.1 通用规则

| 规则 | 内容 |
|---|---|
| 挨在一起 | 每个组合有 1 座核心建筑，其他成员的边缘离核心约 10 m 内就算；含采矿场、煤矿的放宽到约 20 m |
| 道路 | 不要求道路相连 |
| **每座建筑最多 2 个组合** | 制造布局取舍：这座房子给谁用 |
| 重复触发 | 可以，例如两个「小村落」，但要用不同的建筑凑；繁荣度递减（见 4.1） |
| 高级取代低级 | 同一批民居凑成「大杂院」时，不再同时算「小村落」 |
| 成员分配 | 按核心建筑的建造顺序依次分配，结果确定；拆一座只影响它所在的组合，其他组合不重新洗牌 |
| 加成范围 | 只给组合里的成员 |
| 叠加 | 不同组合的加成相加；民居和商店仍受总加成上限约束 |
| 已确定的数值 | 组合不改已确定的维持费金额、能源产出等；需要加成的，写成乘在已确定值上的加成 |
| 和邻里效应 | 建议：邻里效应的机制保留，住宅部分改由「小村落」「大杂院」两个有名字的组合表现，玩家看得见；工业噪音惩罚保留 |
| 发现 | 第一次凑齐弹出「发现组合：XXX！」并点亮图鉴；图鉴显示未发现组合的剪影和一半配方；放置预览提示「再放 1 座 ×× 就成组合」 |
| 被拆 | 组合立刻失效，修好或重建后自动恢复，不再弹窗 |

**原则：每个组合都要有一个看得见的结果**，例如长出东西、外观变化、冒字或明显的数值。

去掉的组合及原因：
- **军需站**：一家杂货铺就让缺钱惩罚失效，而那是维持费唯一的约束。
- **营外酒馆**：等于变相降低维持费，和「当兵的人不算顾客」矛盾。
- **歇脚处**：效果感觉不到。
- **面包飘香**：和小村落几乎一样。
- **矿区**：矿点由地图决定，隐藏等于看运气。
- **黑市**：削弱炼金坊「不能取代宝箱和掉落」的定位。

隐藏组合（冰品铺、望楼酒家、魔法放映会）走「怪但好笑」的配方，制造发现的惊喜。

## 10. 首版经营范围与可见收益（第三轮原型）

S02首切片保留六种店：面包、杂货、酒馆、铁匠、药水、集市，另有电影院。住房、公寓、组合与Lv5科技前置照常；百货/魔导器/雕像/客商连锁暂缓，不列入通关必买，保留图稿及后续目录。15屋8升级240人口+六店种48+合法排他组合40+电影10的示例最终338繁荣，未达Lv6=340，不免费凑分。实际布局地基、组合排他与工人路径仍需验收。

经营让玩家选择住房、工业装备与新服务街区的投入顺序。放店显示全城净增/分钟、覆盖新增空闲居民、招募/组合用途，单店营业额留详情；允许净增0或负。招兵/住宅预览完成后空闲人口和净收入。装备预览按具体新兵基础属性计算，先做护甲和药水，护盾留后续；不为既有兵免费追溯装备。

大波战报与休整建议合为一处，一次突出一个可忽略建议，避免连续模态弹窗；记录实际装备承担伤害、商圈净增、营地材料订单去向，不把服从提示当自主选择。不新增食物/需求/物流/政策槽。

经营保障池在首个S02切片采用六个不同ID：Lv2开放夜市灯火、招兵买马、旧房翻新、警钟；Lv3加入公共建筑扩建、集市繁荣。招兵买马最高2级，其余选过不再出现。警钟复用现有卡，不加入15张战斗首池。依赖对象必须在本配置已经实现且已解锁，可以尚未建造，但显示“待建造××后生效”；尚未招兵时警钟显示“需附近士兵才有援军效果”，不得显示已兑现收益。该规则不放宽战斗首槽“当前立即可用”。未满级可升级候选权重仍×1.3。

经营奖励每手显示 `min(3,有效不同ID数)`，实际2选1或3选1，禁止同ID不同等级凑选项。发布配置须穷举合法领取顺序，保证每次至少2个不同有效ID；不足2报内容配置错误，补实现/补池/修配置后发布，不能静默跳奖励或强迫单选。第四轮六池枚举64种实现子集，仅全六通过；全六的455个选择状态、936条完整Lv2–6领取序列，最少候选4/5/4/3/2。旧五池缺警钟时Lv6仅剩1项，已由新原型规则补足。以上仅是全部依赖实现并按时解锁的配置证明，实际运行与读档仍须校验真实实现标志、解锁、满级排除及其他过滤；尚未验证游戏实现。S01-L较小商店范围另验，Lv7以上若开放领取也需另验，不扩张本保证。

## 11. 暂定与待决

以下为按评审建议暂定的做法，**用户尚未确认**：

1. **城镇经营选择**：首切片按第10节六张经营保障卡与真实2–3选原型执行，覆盖可达Lv2–6；后续完整商圈补池再验，不继续强求15卡或另造政策槽。
2. **邻里效应**：暂定机制保留，住宅部分改由「小村落」「大杂院」两个组合表现。
3. **冒险换收益**：暂定接受。矿工宿舍、城门客栈、前哨站鼓励把建筑放到危险的地方。
4. **城镇等级的名字**：暂用「落脚营地 → 拓荒村 → 定居镇 → 集镇 → 城镇 → 开拓之城」，可改得更有异星味道，例如「着陆营地 → … → 星港之城」。
5. **以后的战役模式**：城镇等级要不要随基地跨关延续，按连续章节/独立战役的关卡配置确定。
6. **数值**：繁荣度门槛、消费池金额、商店价格、组合加成，全部待试玩确定。
