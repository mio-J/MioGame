## 1. 问题

现在的经营基本是一条线：造民居 → 人口自动产金币 → 金币用于造塔、招兵、付维持费。玩家在经营上能做的决定很少；邻里效应、踩出来的路都在后台起作用，玩家感觉不到。

## 2. 已确定（2026-10-07）

1. 采用四项：**建筑组合、城镇等级、商店街、小反馈（飘字等）**。
2. **城镇等级只解锁经营类内容**（民居、商店、装饰、组合等），塔仍由升本解锁。两条线：
   - 本数管打仗；
   - 城镇等级管过日子。
3. **科技升本门槛**由「总人口」改为「城镇等级」。魔法看英雄等级，科技看城镇等级。
4. **瓦房、公寓**由城镇等级解锁。
5. **电影院、市政厅**由研究院 2 本 / 3 本改为城镇等级解锁，研究院只管打仗。

以上第 3–5 条已同步写入[科技系统](科技系统.md)、[民居](../建筑/民居.md)、[电影院](../建筑/电影院.md)、[市政厅](../建筑/市政厅.md)。

## 3. 人口与金币（叠加，不改原规则）

民居照常赚钱：每名人口每分钟 9 金币，这条已确定的规则不变。商店是额外收入，叠加在上面。

人口的用处：

| 用处 | 说明 |
|---|---|
| 交税 | 每人每分钟 9 金，基础收入 |
| 出兵 | 开拓者、士兵从人口中出，被占用的人不交税 |
| 当顾客 | 商店的生意来自附近居民（及上下班路过的人流），附近人越多，商店赚得越多 |
| 繁荣度 | 人口是繁荣度的大头，决定城镇等级 |

## 4. 城镇等级

### 4.1 繁荣度

繁荣度是一个数，攒够了城镇就升一级。它按「现在有多少」计算，不是累计值，所以会涨也会跌；**城镇等级只升不降**。

| 来源 | 怎么算（样例，待定） | 大致占比 |
|---|---|---|
| 人口 | 每 1 名**已入住**居民 1 点；去当兵、当开拓者的人也算（不然招兵会掉繁荣度） | 约 60% |
| 组合 | 每个成立的组合按档次给 5 / 10 / 20 点；同一种组合第 2 次给一半，第 3 次起给四分之一，最多算 5 次 | 约 20% |
| 商店 | 按城里商店的**种类数**计，不按座数 | 约 15% |
| 公共建筑 | 电影院 +10、市政厅 +20、地标 | 约 5% |

- 装饰首版不让玩家手摆（操作量太大），自动长出来的装饰不算分。
- 建筑被拆时，它提供的繁荣度立刻扣掉，原地冒灰色「−繁荣 X」。繁荣度跌到当前等级线以下没有惩罚，只是进度条变灰。
- 界面只强调两件事：**人口最重要**；**凑新组合、开新种类的店能冲一截**。递减规则不用讲，玩家第二次只看到小数字就懂了。
- 显示：资源栏旁的城镇徽章和进度条；鼠标悬停显示各来源明细和「下一级解锁」。

### 4.2 等级表（数值待定，以试玩为准）

| 级 | 名称（暂定） | 繁荣度 | 约需人口 | 预计到达 | 解锁 | 科技门槛 |
|---|---|---|---|---|---|---|
| 1 | 落脚营地 | 0 | — | 开局 | 木屋；面包房、杂货铺 | — |
| 2 | 拓荒村 | 30 | 约 20 | 约 3–5 分钟 | 瓦房；酒馆、铁匠铺 | — |
| 3 | 定居镇 | 90 | 约 55 | 约 12–15 分钟 | 电影院；药水铺、集市 | 研究院可建（科技 2 本） |
| 4 | 集镇 | 200 | 约 120 | 约 25–30 分钟 | 公寓；旅馆；**主城换新外观**；居民换新形象 | — |
| 5 | 城镇 | 350 | 约 150 | 约 40–50 分钟 | 市政厅；电器行 | 研究院可升 3 本 |
| 6 | 开拓之城 | 500 | 约 220 | 约 60–70 分钟 | 百货公司、魔导器专卖店；地标（主角雕像）；主城金色外观 | — |

- 预计时间已经算上了地盘、开拓者人手和防守的拖慢。只靠造民居会更快，钱不是瓶颈：第 30 座木屋 535 金，6 分钟就能回本。Lv2 以后，瓦房要钢铁，钢铁会成为升级的瓶颈。
- Lv6 提前到约 60–70 分钟，保证大多数玩家能用上后期店。
- **科技门槛的变化**：
  - Lv3 约 55 人，对应原来的「人口 50」，基本一致；
  - Lv5 约 150 人，**比原来的「人口 120」难一些**，需要试玩确认。
- **每次升级额外选一次增益**，一局最多多 5 次。和大波后的选择同一个界面，同时到就排队。从哪个卡池抽见第 11 节（暂定只从经济类抽）。
- 电影院、市政厅的效果、范围、能源、维持费都不变，只改解锁条件。能源提醒：市政厅占 200、研究院 3 本占 400，合计要 600 以上，而出生点附近只保证一个煤矿（+300）。

## 5. 商店

### 5.1 通用规则（只用一套「消费池」公式）

| 规则 | 内容（数值待定） |
|---|---|
| 消费池 | 每名已入住的居民，每分钟最多带来约 **1.5–2 金**生意。每名居民只算一次 |
| 分给谁 | 居民的这份钱，平分给他家附近约 15 m 内的不同种类商店。一片街区开 2–3 种店最赚，再多只是分钱 |
| 同种店 | 同种店服务范围重叠时，平分顾客 |
| 上限 | 商店收入和民居的各种加成一起，计入[城市形成](城市形成.md)的总加成上限（+100%），避免金币通胀、架空电影院 |
| 玩家看到的 | 只看**店铺星级**（★1–★3），公式藏在后面；建造预览显示「预计每分钟 +X 金」 |
| 人口、维持费 | 不占人口；低级店没有维持费，高级科技店占用能源 |
| 占地、价格 | 3 × 3 m；同种店价格逐座递增；具体价格待定 |
| 道路、路人 | 门前道路倍率和路过人流放到「踩出来的路」做好之后再加，首版不做 |
| 附加作用 | 两种：① 招募时加成（只给之后招的兵）；② 店附近的范围光环。同种店的附加作用不叠加 |
| 招募时加成 | **每个兵最多带 1 项**（护甲、药水、护盾），带更好的那一项；单位面板显示「新兵已带：药水」 |
| 魔晶 | 没有产魔晶的店，维持「魔晶只来自打怪和宝箱」 |

界面上把消费池写成「每名居民最多带来 X 金生意」，不叫「零花钱」，免得玩家以为钱是从税里扣的。

|---|---|---|---|---|

| 铁匠铺 | 武装新兵 | 收入低，有噪音 | 附近兵营之后招的近战兵护甲 +1 | 2 |
| 药水铺 | 魔法味的民生店 | 中等 | 附近圣堂、法师营地之后招的兵带 1 瓶药水，残血时自动喝 | 3 |

去掉的店及原因：
- **澡堂**：效果只是抵消惩罚，和「矿工宿舍」重复。
- **咖啡馆**：「招兵更快」和「军属大院」重复。
- **报社**：道路是踩出来的，「同一条街」没法定义。
- **占卜摊**：和《出怪系统》「预警后面再定」冲突，等预警定了再考虑。
- **裁缝铺、照相馆**：作用太弱。

另外，**被攻击报警**改为免费的基础界面功能，不再是电器行的奖励。

## 6. 建筑组合

### 6.1 通用规则

| 规则 | 内容 |
|---|---|
| 挨在一起 | 每个组合有 1 座核心建筑，其他成员的边缘离核心约 10 m 内就算；含采矿场、煤矿的放宽到约 20 m |
| 道路 | 不要求道路相连 |
| **每座建筑最多 2 个组合** | 制造布局取舍：这座房子给谁用 |
| 重复触发 | 可以，例如两个「小村落」，但要用不同的建筑凑；繁荣度递减（见 4.1） |
| 高级取代低级 | 同一批民居凑成「大杂院」时，不再同时算「小村落」 |
| 成员分配 | 按核心建筑的建造顺序依次分配，结果确定；拆一座只影响它所在的组合，其他组合不重新洗牌 |
| 加成范围 | 只给组合里的成员 |
| 叠加 | 不同组合的加成相加；民居和商店仍受总加成上限约束 |
| 已确定的数值 | 组合不改已确定的维持费金额、能源产出等；需要加成的，写成乘在已确定值上的加成 |
| 和邻里效应 | 建议：邻里效应的机制保留，住宅部分改由「小村落」「大杂院」两个有名字的组合表现，玩家看得见；工业噪音惩罚保留 |
| 发现 | 第一次凑齐弹出「发现组合：XXX！」并点亮图鉴；图鉴显示未发现组合的剪影和一半配方；放置预览提示「再放 1 座 ×× 就成组合」 |
| 被拆 | 组合立刻失效，修好或重建后自动恢复，不再弹窗 |

**原则：每个组合都要有一个看得见的结果**，例如长出东西、外观变化、冒字或明显的数值。

去掉的组合及原因：
- **军需站**：一家杂货铺就让缺钱惩罚失效，而那是维持费唯一的约束。
- **营外酒馆**：等于变相降低维持费，和「当兵的人不算顾客」矛盾。
- **歇脚处**：效果感觉不到。
- **面包飘香**：和小村落几乎一样。
- **矿区**：矿点由地图决定，隐藏等于看运气。
- **黑市**：削弱炼金坊「不能取代宝箱和掉落」的定位。

隐藏组合（冰品铺、望楼酒家、魔法放映会）走「怪但好笑」的配方，制造发现的惊喜。

## 7. 打仗与经营互相影响

| 机制 | 内容 |
|---|---|
| 凯旋 | 打赢大波后，全城商店约 1 分钟生意翻倍，冒金币、放烟花 |
| 战时萧条 | 交战区附近的商店生意暂时下降，鼓励把商业区放在内圈 |
| 夜里的张力 | 酒馆、不夜城夜里赚钱，但夜里也危险 |
| 外围冒险 | 矿工宿舍、城门客栈、前哨站鼓励把建筑放到危险的地方，换收益 |

## 8. 小反馈（开罗风格，克制）

| 事件 | 冒什么 | 特效 | 限制 |
|---|---|---|---|
| 收税、商店进账 | 小金币图标（不冒字），「叮」一声 | 无 | 每座建筑隔一阵冒一次 |
| 顾客进店 | 小爱心或音符 | 无 | 稀疏 |
| 民居住满 | 「满员 +10 人」 | 烟囱冒一次烟 | 每座每级一次 |
| 组合成立 | 「组合！小村落 +5 繁荣」（金色） | 相关建筑描边闪一下 | 第一次弹大提示，之后只冒小字 |
| 商店升星 | 「生意兴隆 ★★」 | 门口撒几颗金币 | 每家店最多每 60 秒一次 |
| 城镇升级 | 顶部横幅「升级为 定居镇！」 | 主城上空烟花，居民跳起来欢呼 | 大波中只显示横幅，其余等这波打完 |
| 建筑被拆 | 灰色「−繁荣 X」 | 无 | 2 秒内同类合并 |
| 新解锁 | 建造栏图标亮起，加「新」角标 | 无 | 不冒字 |
| 阶段小结 | 每次大波后一张小报：本阶段收入、新发现的组合、最赚的店 | 无 | 和增益选择一起出现 |
| 图鉴完成度 | 发现 5 / 10 / 15 个组合时各给一点小奖励 | 无 | — |

- 同屏飘字最多 3 条，同类合并；大波期间经营类飘字全部隐藏。
- 设置里可以一键关闭飘字。

## 9. 与已确定规则的关系（已同步修改）

| 已确定规则 | 出处 | 处理 |
|---|---|---|
| 科技升本门槛 = 总人口 | 科技系统 第 3 节 | 改为城镇等级 3 / 5；同步改第 3.1 节样例 |
| 电影院是「2 本建筑」、市政厅是「3 本建筑」 | 电影院、市政厅 状态栏 | 改为城镇等级解锁 |
| 邻里效应已确定要做 | 城市形成 | 机制保留，住宅部分由组合表现 |
| 出怪预警后面再定 | 出怪系统 | 不做占卜摊，不冲突 |
| 魔晶只来自打怪和宝箱 | 核心玩法循环 | 没有产魔晶的店和组合，不冲突 |
| 升本只影响之后招募的单位 | 兵营等 | 招募时加成只给新兵，不冲突 |
| 维持费金额（民兵 5、箭塔 10 等） | 核心玩法循环 5.2 | 组合不改这些金额 |
| 人口每分钟 9 金、民居没有维持费 | 核心玩法循环 | 商店叠加在上面，不冲突 |

## 10. 首版最小范围（建议先做这些）

- **城镇等级**：做到 Lv4（解锁瓦房、公寓）。繁荣度先只算「人口 + 组合」。
- **商店 3 种**：面包房、杂货铺、酒馆。只用消费池公式，附加作用先只做面包房。
- **组合 5 个**：小村落、大杂院、军属大院、矿工宿舍、城下町。
- **飘字 4 种**：组合成立、城镇升级、民居住满、−繁荣。

需要的底层机制，大部分能和随机增益共用：
- 建筑基类和事件总线；
- 按格子查「附近多少米内有哪些建筑」的空间索引；
- 属性修正系统（加成相加有上限，减伤乘法）；
- 招募时加成；
- 经济结算；
- 繁荣度与等级解锁表；
- 组合匹配器；
- 三选一界面；
- 飘字管理。

## 11. 暂定与待决

以下为按评审建议暂定的做法，**用户尚未确认**：

1. **城镇升级多给的那次增益**：暂定只从经济类增益里抽，经济卡要补到 15 张左右。否则一局增益数量多出约 50%，战斗流派会被冲淡。备选做法：
   - 单独做一组「城镇特权」三选一；
   - 只在 Lv3、Lv5 两次给。
2. **邻里效应**：暂定机制保留，住宅部分改由「小村落」「大杂院」两个组合表现。
3. **冒险换收益**：暂定接受。矿工宿舍、城门客栈、前哨站鼓励把建筑放到危险的地方。
4. **城镇等级的名字**：暂用「落脚营地 → 拓荒村 → 定居镇 → 集镇 → 城镇 → 开拓之城」，可改得更有异星味道，例如「着陆营地 → … → 星港之城」。
5. **以后的冒险模式**：城镇等级要不要随基地跨关延续，冒险模式恢复时再定。
6. **数值**：繁荣度门槛、消费池金额、商店价格、组合加成，全部待试玩确定。
