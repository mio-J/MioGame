## 1. 定位

任务系统**保持轻量**（已确定）：不是固定流程，也不是每天刷新的任务板，而是**偶尔（极少）发布一个任务**，像一件小事件，打破正常节奏。

奖励是**特殊物品**（已确定），带永久效果，不是直接给资源。例如：

> 让每名居民的收入增加 20 金币的东西。

这类奖励花钱买不到、只有做任务才能得到，所以即使任务很少出现，玩家也有理由接。

## 2. 任务发布（设计提案）

| 规则 | 内容 |
|---|---|
| 频率 | **极少**：S01内部短测关闭；S02完整局最多1次可选事件，在已进行30分钟后的首次非最终大波休整中候选，预计还剩至少15分钟才发布。更长配置另按30–40分钟间隔校准 |
| 同时数量 | 同一时间最多 **1** 个任务 |
| 发布者 | 由[古塞奇尤](../单位/古塞奇尤.md)发布，符合她代理领主的身份，用一两句话说明情况 |
| 时限 | S02候选10分钟，超时消失；长局可用原2–3天（20–30分钟）提案。目标应在时限内实际可达，不使用无船的跨海营地 |
| 接取 | 玩家可以接，也可以无视，不接没有任何影响 |
| 失败 | 失败或超时**没有惩罚**，只是拿不到奖励 |
| 放弃 | 可以随时放弃，没有惩罚 |
| 避开危险时刻 | 不会在大规模进攻的过程中发布，避免打断 |

## 3. 任务类型（设计提案）

只做少数几种，模板简单，每次换目标和奖励：

| 类型 | 内容 |
|---|---|
| **远征** | 清除远处的绿皮营地，或到某个地点取回物品 |
| **坚守** | 在指定地点坚守一段时间 |
| **狩猎** | 击杀指定的敌人，例如一个精英或首领 |

任务的难度和风险与奖励物品的强度挂钩。每个任务发布时就显示目标、时限和奖励物品的名字与效果，玩家可以先看清楚再决定。

## 4. 奖励：特殊物品（已确定）

### 4.1 规则

| 规则 | 内容 |
|---|---|
| 类型 | 带**永久效果**的特殊物品，获得后一直生效 |
| 来源 | 只能通过任务获得，不能购买 |
| 唯一 | 每种物品一局只能获得一次，不会重复 |
| 叠加 | 不同物品的效果可以相加，同一物品只有一份 |
| 显示 | 获得后在界面上有一个物品栏，列出已有物品与效果 |
| 数量 | S01为0件，S02最多1件；长局按实际发布次数计算，不再笼统承诺每局4–8件。没有栏位上限 |

### 4.2 物品样例（设计提案）

| 物品 | 效果 |
|---|---|
| **丰饶之种** | 每名空闲人口每分钟额外 +20 金币（已确定的示例） |
| 匠人锤 | 开拓者建造与修理速度 +20% |
| 矿工护符 | 采矿场钢铁产出 +10% |
| 魔晶罗盘 | 敌人掉落魔晶的概率 +5 个百分点 |
| 古老图册 | 显示地图上所有宝箱的位置 |
| 战旗 | 所有士兵生命值 +5% |
| 守城号角 | 城墙与城门生命值 +10% |
| 学者笔记 | 升本与研究花费 −10% |
| 星盘 | 古塞奇尤获得的经验 +20% |
| 暖炉 | 夜间友方单位视野缩小的幅度减半 |

### 4.3 数值参考

「丰饶之种」让人均收入从每分钟 180 金币变成 200，相当于全体居民收入 +11%。在 300 人口时每分钟多 6000 金币，是很强的物品，所以**必须靠很少的任务来限制**，不能频繁发放。

## 5. 与其他系统的联系

- 奖励是永久加成，与[电影院](../建筑/经营建筑/电影院.md)、[市政厅](../建筑/经营建筑/市政厅.md)的加成可以相加，但要避免总加成失控，需要在定数值时一起考虑。
- 远征类任务需要军队离开基地，与「扩张与防守」的核心矛盾一致，见[核心玩法循环](../核心玩法循环.md)。
- 「古老图册」这类物品会让宝箱探索的价值提升，与魔晶来源联动。

物品不计入基础通关预算；即使不接任务也应有可行路线。奖励中的金币附加与民居/商店统一受[城市形成](城市形成.md)的居民总加成空间约束，不在账本之外另乘一次。无敌、减伤、攻速等结算使用[战斗与护甲规则](战斗与护甲规则.md)。

### 营地遗物实验（实验，默认关；设计提案，第五轮）

本文 4.1「来源：只能通过任务获得」（已确定）**不改**。仅在试玩配置里做以下实验，默认关闭，不进基线：

- **遗物作为营地补给的第三选项**：约 1/4 的营地补给选项为「C 魔晶 / 2C 钢铁 / 遗物」，是三选一中的一项，不是额外附送；遗物沿用本文 4.2 的物品样例与「一局一次、不叠加同名」规则。
- **保守替代**：S02 的唯一任务固定为「去某营地取遗物」，遗物仍经任务获得，不触碰「只能通过任务获得」。
- **转正的迁移影响**（若实验转正，需先改已确定文字）：营地补给由二选一变三选一；重算 500 / 680 魔晶供应；寻宝人（见[随机增益](随机增益.md)）与遗物功能重叠，需二选一。详见[地图与资源点](地图与资源点.md) 6.1.2 备注。
