## 1. 定位

任务系统**保持轻量**（已确定）：不是固定流程，也不是每天刷新的任务板，而是**偶尔（极少）发布一个任务**，像一件小事件，打破正常节奏。

奖励是**特殊物品**（已确定），带永久效果，不是直接给资源。例如：

> 让每名居民的收入增加 20 金币的东西。

这类奖励花钱买不到、只有做任务才能得到，所以即使任务很少出现，玩家也有理由接。

## 2. 任务发布（设计提案）

| 规则 | 内容 |
|---|---|
| 频率 | **极少**：平均每 30–40 分钟（约 3–4 天）发布一次，具体时间带一点随机 |
| 同时数量 | 同一时间最多 **1** 个任务 |
| 发布者 | 由[古塞奇尤](../单位/古塞奇尤.md)发布，符合她代理领主的身份，用一两句话说明情况 |
| 时限 | 有时限，一般 **2–3 天**（20–30 分钟）；超时任务自动消失 |
| 接取 | 玩家可以接，也可以无视，不接没有任何影响 |
| 失败 | 失败或超时**没有惩罚**，只是拿不到奖励 |
| 放弃 | 可以随时放弃，没有惩罚 |
| 避开危险时刻 | 不会在大规模进攻的过程中发布，避免打断 |

## 3. 任务类型（设计提案）

只做少数几种，模板简单，每次换目标和奖励：

| 类型 | 内容 |
|---|---|
| **远征** | 清除远处的绿皮营地，或到某个地点取回物品 |
| **坚守** | 在指定地点坚守一段时间 |
| **狩猎** | 击杀指定的敌人，例如一个精英或首领 |

任务的难度和风险与奖励物品的强度挂钩。每个任务发布时就显示目标、时限和奖励物品的名字与效果，玩家可以先看清楚再决定。

## 4. 奖励：特殊物品（已确定）

### 4.1 规则

| 规则 | 内容 |
|---|---|
| 类型 | 带**永久效果**的特殊物品，获得后一直生效 |
| 来源 | 只能通过任务获得，不能购买 |
| 唯一 | 每种物品一局只能获得一次，不会重复 |
| 叠加 | 不同物品的效果可以相加，同一物品只有一份 |
| 显示 | 获得后在界面上有一个物品栏，列出已有物品与效果 |
| 数量 | 一局大约能拿到 4–8 件，没有栏位上限（设计提案） |

### 4.2 物品样例（设计提案）

| 物品 | 效果 |
|---|---|
| **丰饶之种** | 每名空闲人口每分钟额外 +20 金币（已确定的示例） |
| 匠人锤 | 开拓者建造与修理速度 +20% |
| 矿工护符 | 采矿场钢铁产出 +10% |
| 魔晶罗盘 | 敌人掉落魔晶的概率 +5 个百分点 |
| 古老图册 | 显示地图上所有宝箱的位置 |
| 战旗 | 所有士兵生命值 +5% |
| 守城号角 | 城墙与城门生命值 +10% |
| 学者笔记 | 升本与研究花费 −10% |
| 星盘 | 古塞奇尤获得的经验 +20% |
| 暖炉 | 夜间友方单位视野缩小的幅度减半 |

### 4.3 数值参考

「丰饶之种」让人均收入从每分钟 180 金币变成 200，相当于全体居民收入 +11%。在 300 人口时每分钟多 6000 金币，是很强的物品，所以**必须靠很少的任务来限制**，不能频繁发放。

## 5. 与其他系统的联系

- 奖励是永久加成，与[电影院](../建筑/经营建筑/电影院.md)、[市政厅](../建筑/经营建筑/市政厅.md)的加成可以相加，但要避免总加成失控，需要在定数值时一起考虑。
- 远征类任务需要军队离开基地，与「扩张与防守」的核心矛盾一致，见[核心玩法循环](../核心玩法循环.md)。
- 「古老图册」这类物品会让宝箱探索的价值提升，与魔晶来源联动。
