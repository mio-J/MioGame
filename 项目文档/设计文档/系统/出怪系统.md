## 1. 目标

规定敌人**从哪来、怎么选目标、大波和小波怎么区分**。敌人的强度、种类和每波数量属于后续的波次设计，本文只给一个草案。

## 2. 基本规则

| 规则 | 内容 | 状态 |
|---|---|---|
| 传送门 | 敌人从**传送门**里出来。传送门在**迷雾**中随机刷出，保证各个方向、各个位置都能出怪 | 已确定 |
| 野外营地 | 营地**不出怪**，只当宝箱用：摧毁营地就是开宝箱，见 3.2 | 已确定 |
| 目标 | 敌人朝**离自己最近的建筑**推进并袭击，打掉后再找下一个最近的 | 已确定 |
| 小波 | 常态出现，可以**同时有多个传送门** | 已确定 |
| 大波 | 强度高，传送门**只有 1–2 个** | 已确定 |
| 大波提示 | 大波刷出时提示**哪个方向**有大波敌人袭来 | 已确定 |
| 预警 | 刷出前的预警**后面再定**，目前没有 | 已确定 |

与玩家的[传送阵](../建筑/传送阵.md)是两回事，传送门的正式名称待定。

**大波和小波的区别：**小波是持续的压力，敌人少而散，从多个传送门零星冒出来；大波是一次集中的考验，敌人多而集中，只有 1–2 个传送门，玩家知道大致方向，可以提前准备。

**为什么传送门和营地分开：**
- 如果出怪点是固定的营地，被玩家摧毁后就要补充，还容易出现某个方向长期没有营地、敌人总从同一边来的问题。
- 传送门是随机刷的，不受地图上固定点位限制，各个方向都可能出怪。
- 营地则专心当探索目标和宝箱，和「世界探索」相连。

## 3. 传送门与野外营地

### 3.1 传送门的刷点（设计提案）

| 规则 | 内容 |
|---|---|
| 视野 | 必须在所有玩家建筑（哨塔、塔、建筑自带视野）和单位的视野之外 |
| 距离 | 离**最近的玩家建筑** 120–250 m。太近没有迷雾的意思，太远敌人要走太久（250 m 约 83 秒） |
| 可达 | 必须和至少一个玩家建筑在**同一块大陆**、地面能走通。不刷在被海隔开的岛上 |
| 位置 | 满足上面条件的位置里**纯随机**选，不做方向轮换 |
| 间隔 | 同一波的多个传送门之间保持一定间隔，避免刷在同一处 |
| 持续时间 | 刷完这一波就关闭，不留在地图上（能否摧毁留待定） |
| 不算建筑 | 城市装饰、路灯等不算「建筑」，不会被当作目标，也不影响刷点距离 |
| 世界边界 | 不刷在世界边缘的海岸带 |
| 海上石油平台 | 敌人走不到，不会被选为目标 |

### 3.2 野外营地（宝箱）

营地只承担宝箱的职能，**不出怪，不参与波次**。

| 规则 | 内容 | 状态 |
|---|---|---|
| 摧毁 | 摧毁营地就是开宝箱 | 已确定 |
| 奖励 | **就是宝箱的机制**：魔晶为主（30–60），有时附带金币或钢铁，按距离分带，见[地图与资源点](地图与资源点.md)第 6 节 | 已确定 |
| 守卫 | 营地周围驻守静止的绿皮，玩家靠近才会被惊动；它们不参与波次 | 设计提案，数量后面再定 |
| 生命值 | 后面再定 | 待定 |
| 位置 | 在陆地上、迷雾内，**离出生点至少 300 m**，不能贴着主城 | 设计提案 |
| 数量 | 陆块面积 ÷ **50 000 m²**（约 224 m 见方）四舍五入，全世界大约 40 个；面积不足约 20 000 m² 的碎小陆块不放 | 设计提案 |
| 间隔 | 营地之间至少相隔约 100 m，避免扎堆 | 设计提案 |
| 刷新 | 世界一次性生成，摧毁后**不再补充**（沿用宝箱「开过不再刷新」）。如果魔晶来源不够，再考虑补充 | 设计提案 |

营地不再需要「方向保底」，因为出怪不依赖它。

## 4. 目标选择（设计提案）

- 敌人的目标是**离自己最近的建筑**，含城墙、塔、采矿场、主城等所有建筑（不含装饰）。
- 目标被毁，或前进途中警戒范围内出现单位或建筑时，重新选：警戒范围内先打最近的目标，这与[普通绿皮](../敌人/普通绿皮.md)现有行为一致。
- 遇墙就近拆墙的规则不变。[攀墙鬼](../敌人/攀墙鬼.md)例外：直接翻越。
- 不撤退，打到死为止。

**含义：**外围的建筑最先挨打，[城墙](../建筑/城墙.md)自然成为第一道防线。传送门刷在哪个方向，哪边的建筑就先被袭击，玩家在远处建的采矿场、[炼钢厂](../建筑/炼钢厂.md)因此有风险，与[距离加成](地图与资源点.md)（越远越赚）的「高风险高回报」相呼应。

## 5. 大波提示（已确定）

大波敌人刷出时，向玩家提示方向，例如「**东南方向有大波敌人袭来**」。

设计提案：
- 方向以主城为中心，划分为 8 个方位（北、东北、东……）。
- 有两个传送门时，分别提示。
- 小波不提示。
- 提示在传送门开启的同一时刻发出；预警（提前一段时间提示）后面再定。

## 6. 波次机制（设计提案，参考《植物大战僵尸》）

### 6.1 点数预算

每种敌人有一个**点数**，代表它的威胁。每一波有一份**点数预算**，系统从当前允许出现的敌人里随机挑，直到预算花完。这样不用手写每一波的配置，数值调整也只需要改点数和预算曲线。

| 敌人 | 点数 | 最早出现波次 | 备注 |
|---|---|---|---|
| [普通绿皮](../敌人/普通绿皮.md) | 1 | 第 1 波 | |
| [绿皮弓手](../敌人/绿皮弓手.md) | 2 | 第 4 波 | |
| [孢囊怪](../敌人/孢囊怪.md) | 3 | 第 6 波 | 按母体计，分裂出的个体不另算 |
| [攀墙鬼](../敌人/攀墙鬼.md) | 3 | 第 8 波 | |
| [投矛绿皮](../敌人/投矛绿皮.md) | 3 | 第 10 波 | |
| [破咒小子](../敌人/破咒小子.md) | 4 | 第 12 波 | |
| [铁皮绿皮](../敌人/铁皮绿皮.md) | 5 | 第 14 波 | |
| [野猪骑手](../敌人/野猪骑手.md) | 5 | 第 16 波 | |
| 孢巢母体 | 8 | 第 18 波 | 见孢囊怪 |
| [巨怪](../敌人/巨怪.md) | 20 | 第 20 波 | **只在大波出现** |

点数大致按等效生命值和特殊能力估算，可随平衡调整。

**预算曲线（草案）：**

| 波次 | 预算 |
|---|---|
| 第 N 个小波 | 约 2 + 0.8 × N（第 1 波 3 点，第 10 波 10 点，第 30 波 26 点） |
| 大波 | 同一波次小波预算的 **2.5–3 倍** |

一波有多个传送门时，预算随机拆成若干份，分给各个传送门。

### 6.2 波次的触发

| 规则 | 内容 |
|---|---|
| 倒计时 | 上一波刷出后，**60 秒**后刷下一波 |
| 提前触发 | 场上（含还在路上的）本波敌人剩余总生命降到 **50%** 以下，倒计时缩短到 10 秒 |
| 最小间隔 | 两波之间至少 10 秒 |
| 没有敌人 | 场上没有敌人时不会卡住，倒计时照常走 |

**含义：**打得快，下一波来得快；防线太弱、敌人越积越多，就不会有提前触发，倒计时到了仍会来新一波，压力自然叠加。

### 6.3 大波

| 规则 | 内容 |
|---|---|
| 频率 | 每 **15 个小波**一次（十几波一个，参考《植物大战僵尸》的旗帜波）；按每波约 60 秒算，约一天半一次 |
| 触发 | **不会被血量提前触发**，必须等倒计时走满，玩家有喘息时间 |
| 传送门数量 | 1–2 个，按 5 节的规则提示方向 |
| 预算 | 小波预算的 2.5–3 倍 |
| 特殊敌人 | 允许出现只在大波出现的敌人（巨怪） |
| 难度 | 每次大波后，预算曲线整体抬高一档 |

## 7. 待设计内容

| 项目 | 需确定内容 |
|---|---|
| 预警 | 传送门开启前多久提示，小波是否也有提示 |
| 传送门 | 名称、美术、小波传送门数量（草案 1–3 个）、能否摧毁 |
| 营地 | 生命值、守卫规模（后面再定）；每 50 000 m² 一个的密度是否合适；魔晶是否需要补充来源 |
| 波次数值 | 点数、预算曲线、倒计时、大波倍率、成长曲线是否合适 |
| 空中敌人 | 不需要走通，规则单独设计 |
| 无尽模式 | 失败条件、阶段目标 |
| 数量上限 | 同屏敌人过多时的性能保护 |
| 迷雾实现 | 迷雾后期加入；此前用「不在建筑和单位视野内」判定，营地在此之前靠探索到近处才看见 |
| 昼夜配合 | 夜晚是否更强、敌人是否夜视更好（普通绿皮已设夜视不受惩罚） |
