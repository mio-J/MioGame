## 1. 目标

规定敌人**从哪来、怎么选目标、大波和小波怎么区分**。敌人的强度、种类和每波数量属于后续的波次设计，本文只给一个草案。

## 2. 基本规则

| 规则 | 内容 | 状态 |
|---|---|---|
| 传送门 | 传送门就是**迷雾中的野外敌人营地**：敌人从里面走出来，也是玩家可以主动去攻打的目标 | 已确定 |
| 分布 | 世界生成时，在迷雾中散布若干传送门；玩家不知道位置，靠探索发现 | 已确定 |
| 目标 | 敌人朝**离自己最近的建筑**推进并袭击，打掉后再找下一个最近的 | 已确定 |
| 每波 | 每一波**激活营地**，敌人从被激活的营地里刷出来；**一波可以激活多个营地** | 已确定 |
| 小波 | 常态出现，可以同时激活多个营地（草案 1–3 个） | 已确定 |
| 大波 | 强度高，只激活 **1–2 个**营地 | 已确定 |
| 大波提示 | 大波刷出时提示**哪个方向**有大波敌人袭来 | 已确定 |
| 预警 | 刷出前的预警**后面再定**，目前没有 | 已确定 |
| 摧毁 | 传送门可以被玩家摧毁，摧毁后不再出怪，并给予奖励 | 设计提案 |
| 补开 | 摧毁后，隔一段时间在别处迷雾中开新的传送门，保证无尽模式压力不断 | 设计提案 |

与玩家的[传送阵](../建筑/传送阵.md)是两回事，传送门的正式名称待定。

**大波和小波的区别：**小波是持续的压力，敌人少而散，从多个营地零星冒出来；大波是一次集中的考验，敌人多而集中，只用 1–2 个传送门，玩家知道大致方向，可以提前准备。

**为什么做成营地：**
- 玩家有了主动的目标：去端掉一个传送门，比一直守着更有成就感。
- 探索迷雾、开拓远处的矿、遇到宝箱，都有了理由。
- 和[地图与资源点](地图与资源点.md)的距离加成呼应：往外拓展，会碰上传送门。

## 3. 传送门的布置与启用（设计提案）

### 3.1 布置（世界生成时）

| 规则 | 内容 |
|---|---|
| 位置 | 在陆地上、迷雾内，且**离出生点至少 300 m**，不能贴着主城 |
| 分大陆 | 每块陆地都有营地，**初始数量按面积定**（见下）；出生点所在的主大陆上也有，但都在 300 m 以外 |
| 间隔 | 传送门之间保持一定间隔，避免扎堆 |
| 初始数量 | 陆块面积 ÷ **50 000 m²**（约 224 m 见方）四舍五入，全世界大约 40 个；面积不足约 20 000 m² 的碎小陆块不放 |
| 营地守卫 | 每个传送门周围驻守少量静止的绿皮，玩家靠近才会被惊动；它们不参与波次 |

### 3.2 启用（每一波挑哪几个）

| 规则 | 内容 |
|---|---|
| 候选 | 离**最近的玩家建筑**不超过 **400 m** 的传送门才会出怪，太远的休眠。这样敌人走过来不会超过约 2 分钟（3 m/s） |
| 选择 | 小波从候选里随机选 1–3 个营地；大波选 1–2 个；预算按选中的数量随机拆分 |
| 同一个门 | 连续几波不会总用同一个，尽量轮换，让敌人来自不同方向 |
| 没有候选 | 玩家所有建筑周围 400 m 内都没有传送门时，在迷雾里（离最近的玩家建筑 120–250 m）临时开一个 |
| 可达 | 必须和至少一个玩家建筑在**同一块大陆**、地面能走通，不启用被海隔开的传送门 |
| 不算建筑 | 城市装饰、路灯等不算「建筑」，不会被当作目标 |
| 海上石油平台 | 敌人走不到，不会被选为目标 |

### 3.3 摧毁与补开

| 规则 | 内容 |
|---|---|
| 摧毁 | 有生命值，玩家单位或塔打掉后关闭，不再出怪 | 设计提案 |
| 奖励 | **就是宝箱的机制**（已确定）：摧毁营地相当于开宝箱，得到魔晶为主，有时附带金币或钢铁；数量按距离分带，见[地图与资源点](地图与资源点.md)第 6 节 |
| 补开 | **按大陆补充**（已确定）：一块大陆上的营地被摧毁得太多，就要补开新营地，否则没有怪可出 |
| 补开条件 | 该大陆上「未摧毁的营地」数量低于**初始数量的一半**时开始补开（已确定），补到初始数量为止；每次补一个，间隔约 5 分钟（提案） |
| 补开位置（提案） | 迷雾中，离最近的玩家建筑 120–250 m，且不在玩家视野内；同一块大陆，走得通；同样离出生点至少 300 m |
| 补开的营地 | 同样有奖励，但奖励按**离出生点的距离**算，不因为是补开的而更高，避免刷奖励 |

**为什么按大陆补：**每块大陆各自需要有营地，否则敌人没有出口；玩家清空一块大陆，那里的怪就该从别处重新冒出来。这也让玩家在新大陆上「彻底清干净」变成不可能，永远有新的压力。

## 4. 目标选择（设计提案）

- 敌人的目标是**离自己最近的建筑**，含城墙、塔、采矿场、主城等所有建筑（不含装饰）。
- 目标被毁，或前进途中警戒范围内出现单位或建筑时，重新选：警戒范围内先打最近的目标，这与[普通绿皮](../敌人/普通绿皮.md)现有行为一致。
- 遇墙就近拆墙的规则不变。[攀墙鬼](../敌人/攀墙鬼.md)例外：直接翻越。
- 不撤退，打到死为止。

**含义：**外围的建筑最先挨打，[城墙](../建筑/城墙.md)自然成为第一道防线。传送门刷在哪个方向，哪边的建筑就先被袭击，玩家在远处建的采矿场、[炼钢厂](../建筑/炼钢厂.md)因此有风险，与[距离加成](地图与资源点.md)（越远越赚）的「高风险高回报」相呼应。

## 5. 大波提示（已确定）

大波敌人刷出时，向玩家提示方向，例如「**东南方向有大波敌人袭来**」。

设计提案：
- 方向以主城为中心，划分为 8 个方位（北、东北、东……）。
- 有两个传送门时，分别提示。
- 小波不提示。
- 提示在传送门开启的同一时刻发出；预警（提前一段时间提示）后面再定。

## 6. 波次机制（设计提案，参考《植物大战僵尸》）

### 6.1 点数预算

每种敌人有一个**点数**，代表它的威胁。每一波有一份**点数预算**，系统从当前允许出现的敌人里随机挑，直到预算花完。这样不用手写每一波的配置，数值调整也只需要改点数和预算曲线。

| 敌人 | 点数 | 最早出现波次 | 备注 |
|---|---|---|---|
| [普通绿皮](../敌人/普通绿皮.md) | 1 | 第 1 波 | |
| [绿皮弓手](../敌人/绿皮弓手.md) | 2 | 第 4 波 | |
| [孢囊怪](../敌人/孢囊怪.md) | 3 | 第 6 波 | 按母体计，分裂出的个体不另算 |
| [攀墙鬼](../敌人/攀墙鬼.md) | 3 | 第 8 波 | |
| [投矛绿皮](../敌人/投矛绿皮.md) | 3 | 第 10 波 | |
| [破咒小子](../敌人/破咒小子.md) | 4 | 第 12 波 | |
| [铁皮绿皮](../敌人/铁皮绿皮.md) | 5 | 第 14 波 | |
| [野猪骑手](../敌人/野猪骑手.md) | 5 | 第 16 波 | |
| 孢巢母体 | 8 | 第 18 波 | 见孢囊怪 |
| [巨怪](../敌人/巨怪.md) | 20 | 第 20 波 | **只在大波出现** |

点数大致按等效生命值和特殊能力估算，可随平衡调整。

**预算曲线（草案）：**

| 波次 | 预算 |
|---|---|
| 第 N 个小波 | 约 2 + 0.8 × N（第 1 波 3 点，第 10 波 10 点，第 30 波 26 点） |
| 大波 | 同一波次小波预算的 **2.5–3 倍** |

一波激活多个营地时，预算随机拆成若干份，分给各个营地。

### 6.2 波次的触发

| 规则 | 内容 |
|---|---|
| 倒计时 | 上一波刷出后，**60 秒**后刷下一波 |
| 提前触发 | 场上（含还在路上的）本波敌人剩余总生命降到 **50%** 以下，倒计时缩短到 10 秒 |
| 最小间隔 | 两波之间至少 10 秒 |
| 没有敌人 | 场上没有敌人时不会卡住，倒计时照常走 |

**含义：**打得快，下一波来得快；防线太弱、敌人越积越多，就不会有提前触发，倒计时到了仍会来新一波，压力自然叠加。

### 6.3 大波

| 规则 | 内容 |
|---|---|
| 频率 | 每 **15 个小波**一次（十几波一个，参考《植物大战僵尸》的旗帜波）；按每波约 60 秒算，约一天半一次 |
| 触发 | **不会被血量提前触发**，必须等倒计时走满，玩家有喘息时间 |
| 营地数量 | 1–2 个，按 5 节的规则提示方向 |
| 预算 | 小波预算的 2.5–3 倍 |
| 特殊敌人 | 允许出现只在大波出现的敌人（巨怪） |
| 难度 | 每次大波后，预算曲线整体抬高一档 |
