## 1. 目标

大部分建筑可以建在基地里的任何位置，如果没有额外规则，玩家没有理由把它们连成城市，画面上只是一堆散落的建筑。本系统的目标是：**让「放在哪」有后果，城市的形态就会自己长出来**，而不是靠玩家刻意规划。

包含四项机制：

| 机制 | 作用 |
|---|---|
| 踩出来的路 | 道路由使用情况自发形成，形成街道骨架 |
| 邻里效应 | 住宅与工业等互相影响，街区自然分开 |
| 建筑朝向街道 | 建筑自动面向最近的道路，布局有秩序感 |
| 自动装饰 | 居住区密集后自动长出水井、路灯等，画面更有生活气息 |

## 2. 踩出来的路（设计提案）

### 2.1 规则

| 规则 | 内容 |
|---|---|
| 形成方式 | 友方单位和居民经常走过的地面，会逐渐变成道路，不需要玩家建造 |
| 统计 | 地面划分为 1 m 的格子，每格有「磨损值」，友方单位经过一次增加，长期不走则缓慢减少 |
| 道路等级 | 磨损值达到一定程度变成**土路**，继续增加变成**石板路** |
| 磨损来源 | ① 开拓者、士兵、英雄等真实单位走过；② **居民的通勤流量**：居民只是画面动画，不是真实单位，所以按「每座民居到目的地的路线」估算流量，见第 2.4 节 |
| 敌人 | 敌方单位走过**不留下**道路，也不享受道路加成，避免道路帮了绿皮（已确定） |
| 消退 | 不再有人走的路缓慢褪色、变回原地面 |

### 2.2 数值（设计提案）

| 项目 | 提案值 |
|---|---|
| 格子大小 | 1 m × 1 m |
| 每次经过 | 磨损值 +1 |
| 居民通勤流量 | 每 2 秒，路线上每格 +0.33 × 该民居的入住率（住满为 1），见第 2.4 节 |
| 土路阈值 | 磨损值 ≥ **20** |
| 石板路阈值 | 磨损值 ≥ **60** |
| 消退速度 | 每 30 秒磨损值 −1，最低为 0 |
| 土路加成 | 友方单位移动速度 **+10%** |
| 石板路加成 | 友方单位移动速度 **+20%** |
| 道路上限 | 速度加成不与其他加速效果叠加超过 +40% |

### 2.4 居民通勤流量（设计提案）

玩家只是放房子，居民是刷出来的动画，不是真实单位，没有真的在走路。所以居民对道路的贡献采用**估算流量**：

| 规则 | 内容 |
|---|---|
| 目的地 | 每座民居有 2–3 个目的地：**主城**（必有）、离它最近的**工业或生产建筑**（采矿场、炼钢厂、兵营等，居民去工作）、最近的**电影院或市政厅**（居民去休闲） |
| 路线 | 房屋门口到各目的地门口的导航路径，建筑增减时重算一次并缓存 |
| 权重 | 主城 1.0，工作建筑 0.6，休闲建筑 0.4；再乘以该民居的入住率 |
| 磨损 | 每 2 秒，路线上的格子磨损值 +0.33 × 权重 |
| 动画一致 | 居民动画沿着**同一条缓存路线**生成，画面上看到的人流和道路完全吻合 |

**效果：**玩家只放房子，最先长出来的是主城与住宅之间的路；建了采矿场，居民通勤会把住宅到矿场之间踩成路；建了电影院，住宅与电影院之间也会长出路。**街道自然连接了功能相关的建筑，玩家没有做任何额外操作。**

### 2.3 道路的其他作用（设计提案）

- 道路是[建筑朝向街道](#4-建筑朝向街道设计提案)的依据。
- 民居紧邻道路时，入住速度 +20%（见下）。
- 不允许直接在道路上建造建筑，建造时会自动避开路面，并且**不会因为建造而消除道路**。想占用道路的位置，先让人不再走那里。

## 3. 邻里效应（设计提案）

让建筑的周围环境影响收益，形成「住宅区」「工业区」等自然分区。

### 3.1 民居的邻里效应

| 周围情况 | 对民居金币产出的影响 | 说明 |
|---|---|---|
| 周围 15 m 内每有 1 座其他民居 | **+2%**，最多 **+10%** | 成片的社区更旺 |
| 周围 15 m 内没有其他民居（孤立） | **−10%** | 孤零零的民居收益低 |
| 周围 15 m 内每有 1 座采矿场、炼钢厂 | **−10%**，最多 **−20%** | 工业噪音与污染 |
| 紧邻道路 | 入住速度 **+20%**，不影响产出 | 出入方便 |
| 电影院、市政厅 | 已有，+30%、+45% | 见[电影院](../建筑/电影院.md)、[市政厅](../建筑/市政厅.md) |

- 所有百分比**相加**后再作用于该民居的金币产出。
- 邻里效应不受「不叠加」规则影响，它与电影院、市政厅是分开计算的，最后相加。
- 最终加成范围有上限：总加成最高 **+100%**，最低 **−30%**（设计提案）。商店收入也计入这个上限，见[城镇经营](城镇经营.md)。
- **与建筑组合的关系（暂定，2026-10-07）：**机制保留；「成片 +2%」「孤立 −10%」两条改由组合「小村落」「大杂院」表现，让玩家看得见。工业噪音惩罚保留。见[城镇经营](城镇经营.md)第 6 节。

### 3.2 其他建筑的邻里效应

| 建筑 | 周围情况 | 影响 |
|---|---|---|
| 采矿场、炼钢厂 | 无 | 工业建筑自身不受邻里影响，只会影响附近的民居 |
| 兵营、圣堂、星象殿（生产建筑） | 周围 10 m 内有民居 | 不影响收益，只是画面上会有居民往来 |
| 电影院、市政厅 | 无 | 加成范围本身就是邻里效应的一种 |

### 3.3 界面提示

选中民居时，显示当前受到的邻里影响：每一项带有加号或减号的图标，这样玩家能看出「我的这座民居为什么收益低」，也能主动调整位置。放置民居的预览阶段，也显示预计的影响。

### 3.4 形成的效果

- 玩家会把民居集中建在一起，靠近电影院和市政厅，远离采矿场和炼钢厂，自然形成住宅区。
- 采矿场、炼钢厂旁边不再适合住人，形成工业区。
- 这套机制也增加了一层防守压力：住宅区集中在一起，同时也更容易被一次性攻破。

## 4. 建筑朝向街道（设计提案）

### 4.1 规则

| 规则 | 内容 |
|---|---|
| 目标 | 建筑的正面（门的方向）朝向最近的道路 |
| 触发时机 | 放置建筑时自动计算朝向；预览阶段就能看到最终朝向 |
| 吸附范围 | 12 m 内有道路则朝向最近的道路点；没有道路则朝向主城 |
| 角度 | 吸附到最接近的 90° 方向，再加上 ±3° 的随机微调，避免过于整齐 |
| 手动调整 | 玩家可以手动旋转，手动旋转优先于自动朝向 |
| 已建成后 | 道路事后变化不会改变已建成建筑的朝向 |

### 4.2 适用范围

民居、兵营、圣堂、电影院、市政厅、研究院、法师营地等有明确「正面」的建筑适用。塔、城墙、采矿场（矿点位置固定）不适用。

## 5. 自动装饰（设计提案）

### 5.1 规则

居住区密集到一定程度后，道路两侧和建筑之间会自动出现装饰物，**不影响玩法、不占用碰撞、不阻挡单位**，纯画面表现。

| 周围民居数量（20 m 内） | 出现的装饰 |
|---|---|
| ≥ 1 | 栅栏、花丛、木桶、木箱、柴堆 |
| ≥ 3 | 水井、晾衣绳、手推车、干草堆、菜地、鸡笼 |
| ≥ 6 | 市集摊位（水果、布料、铁器三种）、路灯、旗帜与布告板、长椅 |
| ≥ 10 | 小广场（石板地面）、喷泉或雕像、大集市帐篷 |

### 5.1.1 装饰清单与制作优先级（设计提案）

第一批只做最能表现「生活气息」的 8 件，其余后续逐步补：

| 优先级 | 装饰 | 位置 | 说明 |
|---|---|---|---|
| **第一批** | 木栅栏 | 建筑周围、路边 | 用一小段拼接，可重复 |
| | 花丛 | 建筑旁 | 两三种颜色 |
| | 木桶 | 建筑旁、路边 | 单件或成组 |
| | 木箱 | 建筑旁 | 可叠放 |
| | 水井 | 民居之间的空地 | 有 3 座以上民居才出现 |
| | 晾衣绳 | 两座民居之间 | 有布料飘动的动画更好 |
| | 路灯 | 沿路 | 夜间亮灯，见下方时代变化 |
| | 市集摊位 | 路边空地 | 水果、布料、铁器可以换贴图 |
| **第二批** | 柴堆、干草堆、手推车、菜地、鸡笼 | 民居周围 | 农家感 |
| | 长椅、布告板、旗帜 | 沿路 | 街道感 |
| **第三批** | 小广场地面、喷泉、雕像、大集市帐篷 | 民居最密集处 | 城市中心感 |

### 5.1.2 随时代变化的装饰（设计提案）

装饰随科技本数变化，让城市的外观也体现时代推进：

| 条件 | 变化 |
|---|---|
| 开局（1 本） | 油灯路灯、木质摊位 |
| 研究院建成（科技 2 本） | 路灯换成铁艺煤气灯，出现铁制推车 |
| 研究院 3 本 | 路灯换成电灯，摊位加上遮阳篷 |
| 法师营地建成（魔法 2 本） | 部分路灯换成魔晶灯，发出淡蓝色光 |

这是可选的后续内容，不影响首批制作。

### 5.2 摆放约束

| 约束 | 内容 |
|---|---|
| 不压建筑 | 不与任何建筑的占地重叠，并留出 0.5 m 间隔 |
| 不压道路 | 路灯、摊位等沿路摆放，但不在路面正中 |
| 最小间距 | 同类装饰之间至少 2 m |
| 地形 | 只摆在坡度较平的位置 |
| 建筑盖过来 | 玩家在装饰位置建造时，装饰自动消失，不阻止建造 |
| 随机性 | 用建筑位置做随机种子，同一个布局每次生成的结果相同 |

### 5.3 与其他机制的联系

- 装饰的出现密度与[邻里效应](#3-邻里效应设计提案)的「成片社区」互相呼应：越旺的街区越热闹。
- 夜间路灯、摊位灯亮起，配合[昼夜系统](昼夜系统.md)，城市夜景更有气氛。

## 6. 实现思路

本节是给实现的参考，不属于玩法规则。

**踩出来的路：**
- 用一个低分辨率的二维数组（每格 1 m）记录磨损值。
- **真实单位**（开拓者、士兵、英雄）：每隔约 0.5 秒，把它们当前所在格子的磨损值加 1，不要每帧改。
- **居民是动画，没有真实移动**，所以不追踪居民，而是给每座民居预先算好通勤路线（见第 2.4 节）：在建筑增删时，用导航系统求「门口到目的地门口」的路径，缓存下来，每 2 秒沿着缓存路线给格子加磨损。
- 居民动画沿同一条缓存路线生成，画面与道路一致，不需要额外的寻路。
- 用一张和地图同大小的低分辨率图，记录土路、石板路的遮罩，叠加在地面材质上显示道路。磨损值变化后只更新有改动的区域。
- 移速加成可以在单位移动时查询脚下格子的道路等级。

**建筑朝向街道：**
- 放置时，在以建筑中心为圆心、12 m 半径内，找到最近的道路格子，计算方向向量。
- 把方向吸附到最近的 90°，再加一点随机偏移。
- 预览阶段每次鼠标移动重新计算一次，成本很低。
- 玩家按旋转键时，取消自动朝向，改用手动角度。

**自动装饰：**
- 每次有民居建成或被拆除，只重新计算它附近约 30 m 范围内的装饰。
- 对范围内的候选位置做泊松盘采样，过滤掉压在建筑、道路或陡坡上的位置，再按密度等级挑选装饰类型。
- 装饰用实例化渲染（同一种装饰画成一批），不带碰撞，性能开销很小。
- 夜间需要灯光的装饰，只在有哨塔或路灯的范围内开启灯光，避免大量动态光源。

## 7. 待设计内容

| 项目 | 需确定内容 |
