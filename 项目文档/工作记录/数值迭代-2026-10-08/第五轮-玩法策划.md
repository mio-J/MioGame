## 0. 先说结论（五句话）

1. **这个设计最强的是「取舍有后果」，最弱的是「前十分钟没有压力、也没有选择」。**第四轮样例里 80 钢住宅升级让位给火炮，能改变墙破与否——这是真正的乐趣引擎；但同一份样例里第一阶段（0–10 分钟）几乎没有压力（第三轮条件模型 B 墙最低 1966.7/2000），而开局又是「木屋→箭塔」的已解之题。钩子不能靠加怪，要靠**可选的风险**。
2. **金币宽裕会悄悄贬值整条开罗线。**样例终局现金 28.7 万，维护累计 33 万。凡是只给金币的东西（税收数字、纯金币卡、金币型商店反馈）在后半局选择价值接近 0；稀缺的是钢铁、人口容量、兵营吞吐、魔晶、英雄时间、站位。文档应承认这一点并据此删减和改 UI，而不是继续给金币找用处。
3. **战斗对玩家是「旁观 + 修墙 + 调英雄」，主动动词偏少**；远征对科技路线是**被支配的选项**（2C 钢 ≈ 3–6 分钟的一座矿产量，离家约 5 分钟），而营地发现方式、可见标记在文档里是空白。
4. **「再来一局」目前没有外层理由**：没有难度档、没有目标、没有解锁、没有失败复盘，一局约 50 分钟。最低成本的补法是「自选挑战勋章 + 可复玩的地图种子 + 失败/胜利复盘页」，不碰任何数值。
5. **最值得马上裁决的文档矛盾**：第四轮样例假设英雄「在 180 秒开门时看到方向」，而《出怪系统》写「小波是否提示待设计」。不裁决，这条已被采纳的样例前提就不成立。

## 1. 体验走查

### 1.1 时间轴基准（S02 原型，第四轮样例）

- 准备 120 秒；阶段本地时钟从 120 秒起算；每阶段 3 小波；第 1 阶段小波开启 3:00 / 4:30 / 6:00，大波 7:10。
- 六个大波实际开启：7:10 / 15:25 / 23:27 / 31:45 / 40:00 / 48:17；清场：8:45 / 16:47 / 25:05 / 33:20 / 41:37 / 49:57（合成条件样例，不是保证）。
- 大波自开启到清场仅约 82–100 秒；每次大波清完休整 90 秒；一局约 50 分钟，其中**约 9.5 分钟是大波交战**（六次各约 82–100 秒），约 7.5 分钟是休整（五次，最终波后直接胜利），其余约 33 分钟是「小波 + 普通出怪」的持续低中压。
- 每局玩家的显式选择次数很少：战斗卡 5 次、经济卡最多 5 次（Lv2–6），共约 10 次，平均每 5 分钟一次。其余时间的选择来自「钱和钢花在哪、英雄去哪、塔和墙放哪」。

### 1.3 大波前后的专门走查

- **大波前（约 60–300 秒前）**：普通出怪与小波持续，玩家实际上没有「备战」按钮；唯一的备战信息是「第几次小波」。【假设】没有「阶段条」时玩家无法预判大波何时来，也就无法决定「现在该不该升 3 本、该不该出远门」。
- **大波中**：玩家动词只有：调英雄/兵（普通移动、攻击移动、攻击指定）、开关城门、修墙（工人单工 60 秒才修满 2000 血）、取消工地。卡与塔全是被动。【假设】对 TD 玩家这是合理的「观战 + 救火」；对习惯 RTS 的玩家偏少，需要真人确认。
- **大波后**：休整 90 秒。**这是全局唯一安全的前线施工窗口**（施工中的开拓者在遇袭时随工地死亡，所以其他时段在前线开工本身就是风险）。该事实在文档里只在「建造」章作为风险出现，没有被表述为玩家可利用的节奏。休整内要挤的事：战报、选卡（战斗 3 选 1 + 可能的城镇升级经济卡）、修理（单工 60 秒/墙）、采购/升级、英雄回家、凯旋。

### 1.5 信息不足

1. 小波方向是否提示（文档矛盾，见 2.4）。
2. 营地如何被发现、标记何时出现：《出怪系统》只写「靠探索到近处才看见」，《地图与资源点》写「宝箱是否有远距离可见标记，待定」，而第四轮片段 B 假设玩家「已发现营地标记显示 C 晶/2C 钢、往返时间与阵地风险」。
3. 大波/小波的进度与大波何时来：生存里没有等同战役「顶部进度条」的规定。
4. 休整剩余时间；休整结束后下一次出怪何时恢复。
5. 失败原因：主城被毁后弹什么？战役有回溯，生存只有「本局结束」。
6. 经济面板：金币过剩后，玩家真正需要盯的是钢铁/能源/人口容量/兵营队列，文档没有规定它们的显示优先级。
7. 敌人首次出现的反制提示：破咒小子魔免、攀墙、孢囊爆炸、野猪冲锋等，仅有「首次破咒需明显魔免标记」一句。

### 1.6 操作负担

- **单工人 + 无建造队列 + 全忙则失败不排队**：多个工地同时开时玩家要反复点击重试。样例里修墙已需要专职修理工；金币宽裕会让玩家雇更多工人，但每次召集失败的提示和重试仍是纯操作成本。【假设】这是前 20 分钟最大的无聊/烦躁来源之一，需要用「召集失败次数」验证。
- **修墙**：休整批量维修已缓解；但战斗中仍要单栋点修理。
- **远征**：英雄 + 小队出发/回家的 UI（集合、撤回）文档未写。
- **选卡/升级弹窗**：已规定合并，需落实为单一面板。

## 2. 保护 / 修复清单

### 2.1 最有趣的五件事（要保护）

1. **材料取舍有可归因的后果。**同一笔 80 钢，晚升住宅换 B 炮提前 97 秒，墙是否在 1500.2 秒破、英雄是否 1798.2 秒死都被改变。玩家能说出「我为什么死」「我为什么活」。**保护方式**：别用「防死亡保险」「自动补救」稀释这条因果；休整建议绝不替玩家做这类决定。
2. **随机门 + 「打最近建筑」→ 外围风险与英雄回援。**远矿/前哨/矿工宿舍 combos 鼓励建在危险处；英雄 54 米/18 秒回援是玩家能算的决策。**保护方式**：门位置纯随机不碰；任何情报改动只允许「开门当刻」，不预报。
3. **魔法靠战斗成长、科技靠建设成长（英雄等级 vs 城镇等级）。**两条路线的节奏手感不同，不是同一棵树换皮。**保护方式**：不要为了数值平衡把两门槛统一。
4. **规则型卡牌改变站位而非只加数字。**碎冰+凝滞、阴阳+瓮中、老兵+归营疗养这类卡要求玩家挪塔、轮换兵。**保护方式**：不新增纯数值填槽卡；协同要观察到「选卡后布局变化」，而不是「卡数量」。
5. **开罗式发现与大波后的凯旋节奏。**凑出小村落冒水井、组合图鉴剪影、升级换主城外观；大波期间隐藏经营飘字，赢后 60 秒凯旋集中冒金币放烟花。**保护方式**：大波中的静默与凯旋的爆发是一组对比，不要为「信息」把大波中的飘字放回来。

### 2.2 最危险的五个无聊/坏体验点（要修）

1. **前十分钟：无压力、无情报、无选择**（解法 P01、P03、P05）。
2. **金币过剩 → 开罗数字贬值、纯金币卡成陷阱**（解法 P09、P14，及承认金币是廉价货币）。
3. **大波交战与大波前的旁观感 / 休整的负担过载与安全窗口未被点明**（解法 P05、P07、P15）。
4. **远征对科技路线被支配、且营地发现与标记缺失**（解法 P01、P06）。
5. **失败不可读、通关无复盘、复玩无外层理由**（解法 P04、P10、P11）。

| P07 | 建造/维修「待派工」队列（全忙时挂起，可随时取消全退） | **替代候选** | 单工人 + 不排队的操作负担 | 中 | 否，先用数据判断 |
| P08 | Lv2 首次城镇奖励含一张「起手」战斗卡 | **替代候选** | 第一张战斗卡太晚（8:45）；Lv2 经济卡几乎都是待建 | 中 | 默认不开 |
| P09 | 删除纯金币增益与自动维修、战时萧条、税收递减候选 | **永久删除** | 金币过剩下的陷阱选项；隐藏规则 | 低 | 是 |
| P10 | 通关勋章（自选挑战，纯统计，不改数值）+ 外观奖励 | 新增 | 复玩无目标 | 低 | 是 |
| P11 | 地图种子显示/输入、失败后「同图重来」 | 新增 | 复玩与 A/B 验证 | 低 | 是 |
| P12 | 卡池分层解锁：首版固定 15 战斗卡，其余随勋章逐步入池 | 暂不进首版 | 长期复玩 + 80 卡路线 | 中 | 否 |
| P13 | 生存难度档（预算倍率 + 休整秒数） | 暂不进首版 | 难度可选的已确定方向 | 中（验证成本高） | 否，仅预留字段 |
| P14 | 战报「城镇贡献」行 + 战斗中组合生效的描边反馈 | 新增（反馈） | 经营与战斗两张表 | 低 | 是 |
| P15 | 一键集合/撤回 + 英雄状态条（外出/驻守/阵亡倒计时） | 新增 | 远征操作负担与信息 | 低 | 是 |
| P16 | 英雄主动技 / 全局主动技 | 暂不进首版 | 旁观感（仅当验证信号出现） | 高 | 否 |
| P17 | 面包房/杂货铺合并（仅在试玩触发条件满足时） | 合并候选 | 同价同能力店种 | 低 | 否，等数据 |
| P18 | 局长选项（3/6 大波）作为难度/长度变体 | 暂不进首版 | 50 分钟/局的复玩摩擦 | 低（验证高） | 否，裁决 |

### 3.2 逐项说明（重点项）

#### P01 开局营地线索（开局钩子）

- **问题**：前十分钟压力近 0（第三轮条件模型 B 墙最低 1966.7/2000），开局顺序已解，玩家没有理由抬头看地图。
- **玩家具体选择**：开局时地图上自动出现**最近一个营地**的标记（方向、距离、守卫强度如 4 普 + 1 弓、奖励类型 C 魔晶/2C 钢、预计往返时间）。玩家决定：先造兵营 + 2 民兵带英雄出发（约第 5–8 分钟，之后第一大波前回家），还是守家升级，还是把这次远征推到第一次休整之后。出发的代价：兵营 3000 + 民兵 2×1200 + 英雄缺席期内的经验与火力。**注意**：英雄 600 血，4 普 + 1 弓约 55–60 DPS，**英雄单独去会在十几秒内死亡**，所以这是一次真投资，不是免费探索。
- **被替代/被删减的规则**：只补「营地如何被发现」的空白（《地图与资源点》的「标记待定」是未定项，不是已确定项）。不改营地奖励、守卫、300 米边界、一次性规则。其余营地仍须探索。
- **开发代价**：低（一个「出生时预揭示」标志 + 标记 UI；标记 UI 本来就必须有）。
- **失败条件 / 否决信号**：(a) 超过 5/6 的首玩者在 3 分钟内带英雄单人出发并早亡（说明风险没有读懂，要补 UI 提示而不是撤线索）；(b) 6 人里没有人在第一阶段考虑它（说明标记没起作用，或收益太低）；(c) 玩家 8–10 分钟时的钢铁/魔晶明显高于样例，导致第一次大波压力被碾平（说明提前拿到了不该有的资源，要把线索改成「第一次休整后揭示」）。
- **验证**：同一种子 A/B（有/无线索，各 3 人以上，换序），记录出发时间、出发队伍、返回时间、守家损失、取得奖励的用途、玩家复述的理由。
- **边界**：线索不是预警；不揭示门位置。

#### P02 小波开门方向提示

- **问题**：第四轮样例让英雄「180 秒开门看到方向后走 54 米/18 秒到 B」，《出怪系统》第 5 节却写「普通出怪不提示；小波是否提示待设计」，《生存数值配置》第 5 节例子又说「大波只有开门当刻方向提示」。三处口径不一致。
- **玩家选择**：看到「东南 · 小波」后，英雄去哪、要不要召回远处的工人。无提示时，只能靠「被攻击报警」才反应。
- **规则**：小波开门当刻在小地图边缘闪一个短箭头，不弹模态；普通出怪不提示；大波保持已确定的方向文字提示。**不提前**，不显示合法落点范围，不预知下一次门。
- **替代关系**：补全「小波提示」这一待设计项，不改已确定的「大波提示」「无预警」。
- **代价**：低。
- **失败条件**：玩家反馈「提示让我提前布防」（说明提示被读成了预警——则退回只在被攻击后提示）；或提示导致英雄永远一动不动（因为总有人回援赶得上）——此时说明门户距离范围需数值重看。
- **验证**：记录开门到英雄/兵第一次改变位置的秒数；对比有无提示；观察是否出现「听到提示就去修另一面」的真实调度。

#### P05 休整三步面板

- **问题**：休整 90 秒要承载战报、卡牌、城镇升级卡、修理、采购、凯旋，而文档同时要求「不连续弹三个窗口」。
- **玩家选择**：面板顺序为 ① 一屏战报（击杀、损失、新招装备兵承伤、新商圈净增、营地材料去向）；② 战斗 3 选 1（若同时 Lv 升级则排队的经济卡紧跟）；③ 一条系统建议（可忽略）。选卡不暂停世界，面板可拖到一边。
- **新增一句明示**：「大波清完后是唯一安全的前线施工窗口：此时开工的塔/墙/矿场不会遭遇新刷怪。」休整剩余 15 秒时提示「请让前线工人撤回」。
- **替代**：取代「战报、增益、客商三个连续模态窗口」的写法（第三轮已倾向合并，本条把它落成明确结构）；不新增系统。
- **代价**：低。
- **失败条件**：玩家在休整里连续 30 秒无目标（说明还不够有事做）或相反——反复在面板间切换/点重试（说明负担过载）。
- **验证**：休整内的输入密度、各面板停留时间、「休整结束时仍有工人在前线」的次数、是否有人说「没时间选卡」。

#### P06 营地遗物（把「任务系统」并入营地）——替代候选

- **问题**：科技路线远征被支配（见 1.4）；任务系统在 S02 中最多 1 次、30 分钟后才发布，却要做任务面板、物品栏、10 件物品内容。
- **玩家选择**：约 1/4 的营地标记上显示一个**遗物图标**（如「匠人锤：开拓者建造/修理 +20%」），玩家在看清守卫与收益后决定去不去；遗物与 C 魔晶/2C 钢是**三选一**还是**额外附送**由裁决定（建议三选一，避免叠加收益）。
- **被替代/被删减的规则**：**替代**《任务系统》中「奖励只能通过任务获得」「S02 最多 1 件」（这两句分别是已确定的方向与原型基线）；任务发布流程（古塞奇尤发布、10 分钟时限等）可合并删去或保留一次。迁移影响：任务系统文档要重写获取方式；物品清单（匠人锤/矿工护符等）改为遗物清单；寻宝人（多一次选择）同时被删除或并入。
- **代价**：中：营地数据加一个可选字段 + 遗物物品栏；省去任务面板与发布逻辑，总开发量不增反减。
- **失败条件**：遗物数值让人必须去拿（说明偏强，改数值或改成纯功能性遗物如「古老图册」）；或没人关心（说明遗物没形成差异，应把它并回奖励三选一而不是继续加物品）。
- **验证**：记录遗物营地的访问率、与非遗物营地的出发时机差异；是否因遗物改变英雄/兵去向。

#### P07 待派工队列——替代候选

- **问题**：《建造与修理》写「全都在忙：本次操作不生效、不排队」「新建建筑仍没有建造队列」，而扣费发生在放置时，未开工取消又是全退——本来就具备安全排队的条件。
- **玩家选择**：全忙时仍可放置，工地显示「待派工」，玩家可随时取消（全退）。不改「单工人、施工中不能移动、施工无敌」。
- **被替代**：「全忙则失败」这条设计提案；【不触碰】「只能 1 名开拓者建造」「施工中不可移动」两条已确定规则。
- **迁移影响**：数值组的 244 事件经济模型要补「排队时刻 vs 开工时刻」；现金锁定会提前，需要重跑 1560 秒前后的采购；炼钢/升本订单不应借此改变先后。
- **代价**：中。
- **失败条件**：待派工让「远方空占着工地不开工」成为新的漏洞，或让玩家忽略雇工；若试玩里「召集失败」平均每局 < 5 次，则不采纳。
- **验证**：先只统计「召集失败次数/局」「重试连续次数」；超过阈值再做该候选。

#### P08 Lv2 首次奖励含「起手」战斗卡——替代候选

- **问题**：全局第一张战斗卡在 8:45，而 3–5 分钟的 Lv2 经济卡首手四项几乎全是「待建」，没有即时反馈。
- **规则**：Lv2 的城镇奖励改为「1 张经济 + 1 张战斗（从当前即可用的 15 池中抽）+ 1 张经济」。
- **被替代**：《城镇经营》第 11 节「城镇升级增益只从经济类抽」（用户未确认的暂定项，非已确定）。
- **迁移影响**：战斗卡总数 5 → 6，会抬高第 1–2 阶段防御；战斗数值要重跑第四轮联账；「第二次有效选卡有不同卡关联机会」的保证需重算。
- **默认不开**。只有当试玩出现「4:00–8:45 玩家连续无事可做/厌烦」（≥3/6）时再启用。**优先尝试 P01、P05、P14**，它们不改数值。

#### P09 删除：纯金币类增益与相关候选（永久删除）

| 项 | 为什么删 | 替代/影响 |
|---|---|---|
| 余粮生息（#24） | 黎明按存款 3% 且上限=民居数×140，约千金级；金币宽裕时是「选了没感觉」 | 无；35 张目录里减 1 张 |
| 高利贷（#28） | 现金已 28.7 万的世界里「借钱」没有对象；还欠款，增加存档/排队规则 | 无 |
| 清场奖金（#25）**的金币部分** | 同上；其钢铁部分（点数×1 钢/大波，16–180 钢）反而过强，不能直接保留 | 若要保留，改名并重算为「钢铁赏金」另评；默认删 |
| 闲时维修（#27） | 与 4.6 批量维修的「不自动扫描」意图相反，且鼓励挂机 | 无 |
| 寻宝人（#26） | 每个营地多一次选择会改变选卡总量；与 P06 重叠 | 并入 P06 的遗物，不再加选择 |
| 战时萧条（《城镇经营》§7） | 一个看不见的收入修正；让「净增预览」更难解释；敌人本来就先打最近建筑，不需要它「鼓励放内圈」 | 删除后预览少一项修正 |
| 税收递减（第三轮候选 C） | 本稿主张接受金币宽裕；该候选替代已确定的 180 税收且迁移成本高 | 保留在归档，不进规划 |

- **代价**：低（删文字 + 过滤）。
- **失败条件**：试玩发现后期金币其实缺（≥3/6 玩家说「钱不够」）——说明案头现金宽裕被高估，应恢复讨论，而不是继续删。
- **验证**：每 60 秒记录现金/钢/能源/人口容量，对照玩家主观「钱是否是瓶颈」。

#### P10 通关勋章（自选挑战，不改数值）

- **问题**：生存没有外层目标，复玩全靠随机卡的新鲜感。
- **玩家选择**：开局前不用选；通关结算页根据日志给勋章，玩家下一局自己决定追哪一个（相当于玩家自设规则）。候选勋章（均为纯统计）：
  - 主城全程未受伤 / 英雄全程零阵亡；
  - 不建研究院通关 / 不建法师营地通关；
  - 清除 ≥6 个营地；
  - 发现 ≥12 个组合；
  - 城镇到 Lv6；
  - 实际用时 < 45 分钟（用时短会压缩经济窗口，是玩家自选的难度）。
- **被替代**：无（新增）。奖励仅限外观（主城皮肤、英雄头像框、称号），**不给数值**，不解锁抽卡池（P12 才碰）。
- **代价**：低（统计 + 结算页 + 少量外观）。
- **失败条件**：玩家完全不看勋章（≥4/6 说没注意）；或勋章诱导玩家故意回避核心系统导致体验变差（出现「为了勋章不用卡」的抱怨）。
- **验证**：通关后问「下一局你想做什么」；是否因勋章换路线。

#### P11 地图种子与「同图重来」

- **问题**：复玩时玩家分不清「是我变强了还是图变好」；A/B 验证需要同图。
- **规则**：结算页和主菜单显示地图种子；可输入种子开局；失败页提供「同图重来」。**门户位置仍纯随机**（种子只定地图、矿点、营地），不能借此重现同一串门位置。
- **代价**：低（种子已存档）。
- **失败条件**：玩家把种子当作「刷最佳图」工具并暴露地图质量差异（说明地图合格线没有守住，应回头修生成器，而不是删种子）。

#### P14 战报「城镇贡献」行 + 战斗中组合描边

- **问题**：经营与战斗在文档里已经互相引用（军属大院、城门楼、前哨站、矿山哨所、铁匠/药水），但玩家**看不见**这些在战斗中起作用。
- **玩家选择**：无新选择；让玩家知道「我的街区在打仗里起了什么作用」，从而下次愿意继续这样摆。
- **规则**：战报里加一行：「本阶段：军属大院多招 N 名兵；药水兵承伤 X；矿山哨所挡下 Y」。战斗中，正在生效的战斗型组合在其成员上做 0.5 秒描边闪（沿用「组合成立」的特效，不新增美术）。
- **代价**：低。
- **失败条件**：战报里该行常年为空（说明战斗型组合没有被使用，需要回头看组合设计），或玩家说「看不懂这一行」。

#### P15 一键集合/撤回 + 英雄状态条

- **问题**：远征与回援依赖英雄/小队，UI 没规定「把外面的人叫回来」。
- **规则**：「召回至主城」按钮（英雄+外出队伍，不瞬移，仍走回去）；屏幕角显示英雄状态：驻守/外出/阵亡 + 复活倒计时 + 需 10000 金。
- **代价**：低。
- **失败条件**：玩家用召回来无成本规避所有损失（说明回援太便宜，改为必须自己走回去，不加按钮）。

#### P03 阶段条与休整倒计时

- **规则**：生存顶部用**计数**表示进度（「阶段 3/6 · 第 2 次小波」「大波将至」只在最后一次小波清完后出现），休整显示「休整 62 秒」，休整结束前 15 秒提示。
- **是否算预警**：只给计数不给秒数，不显示方向，不算新增预警；若主策判断「大波倒计时秒数」也算预警，则此项只保留计数。
- **代价**：低。
- **失败条件**：玩家反馈「提示太多」；或「大波将至」让玩家产生被预警的感觉（可改为不显示）。

#### P04 失败复盘页与胜利结算页

- **失败页**（生存主城被毁）：时间线（几点几分哪个方向的门开了、第一座被毁的建筑、主城受损曲线）、英雄是否在场、当时现金/钢/能源/人口、未使用的卡和未花的钢铁、「最薄的一段墙」。只陈述，不指责；一句建议。
- **胜利页**：用时、城市变化（Lv/组合/店种）、核心卡、损失、远征贡献、勋章（P10）、再来一局按钮（P11 种子）。
- **代价**：低–中（数据已有，需要日志与界面）。
- **失败条件**：玩家看完仍说不出死因（≥3/6）；或复盘让玩家觉得被说教。

#### P13 难度档与 P12 卡池分层解锁（暂不进首版）

- **难度档**：提供「平静/标准/凛冬」三档，仅调整每阶段预算倍率（如 ×0.8/×1/×1.25）与休整秒数（120/90/60），**不改敌种构成与门规则**。当前所有数值验证均为标准档，所以首版只在数据里预留 `difficulty` 字段，不开放选择，否则验证面积翻三倍。
- **卡池分层**：首版固定 15 战斗卡 + 6 经营卡；通关次数/勋章逐步把另外 20 张已设计卡与后续新卡放进池。这既是复玩目标，也是 35 → 80 卡路线的自然载体。**必须等首池真人验证后再做**。
- **代价**：中；**否决信号**：首批试玩者在第 2 局前就觉得「卡池没新东西」时才需要提前。

#### P16 英雄主动技 / 全局主动技（暂不进首版）

大波中主动动词偏少，可能让战斗显得旁观。但英雄、卡、塔都已经是数值验证对象，加主动技要全盘重算；首版先验证 P15、P03、命令优先与门的开关是否已足够。**触发条件**：试玩出现「大波时 ≥3/6 玩家说无事可做」。届时优先试「已有英雄闪电的手动聚焦」之类不增加总输出的操作，而不是新增伤害技能。

### 3.3 回答任务要求的五个专题

**① 开局前十分钟的钩子。**不要加怪，加**可选风险**：P01（营地线索）+ P02（小波方向）+ P05（把休整变成有明确利用窗口的节奏）+ 勋章（P10）。开局前三分钟的「已解之题」不再强求改，因为木屋→箭塔本身是有效的教学；真正要补的是 4–8 分钟这段谷底，由远征与「Lv2 首次奖励」（P08，默认关）承担。

**② 城镇经营与战斗的互相影响。**已有且保留：凯旋（赢后 60 秒消费 ×2 + 烟花）、铁匠/药水装备兵、军属大院/城门楼/前哨站/矿山哨所、夜里张力。本轮改动：**删除战时萧条**（隐藏、与目标选择规则重复）；加 **P14**（把已有联动让玩家看见）；承认金币是廉价货币，让经营→战斗的真实通道落在**繁荣门槛（科技 3/5 级）、装备兵、组合、卡池经济选择**，而不是金币本身。**不新增**需求条、政策槽或居民任务。

**③ 大波之间的休整期做什么。**四件事，按优先级：① 看战报（10 秒）；② 选卡（10–20 秒）；③ 修前线并**趁无怪施工**（主体 60 秒，P05 明示）；④ 英雄回家/换装/换站位。不再增加第五件事。若试玩证明仍然空，宁可缩短休整，也不加强制任务。

**④ 战役首个教学关怎么让人想继续玩。**见 3.4。

**⑤ 生存「再来一局」的理由。**目标（P10 勋章）、复玩依据（P11 种子/同图重来）、复盘（P04）、长期解锁（P12，暂缓）、难度（P13，暂缓）、变体（局长 P18，暂缓）。**首版只做 P10 + P11 + P04**，三者都不改任何数值。

## 4. 文档细节补写条目（可直接落文）

每条标明建议落入的文档。凡是尚待裁决的，标「待 §6 裁决」。

### 4.1 《出怪系统》第 5 节「大波提示」补充（待 §6-1）

> **小波提示（原型）**：小波传送门开启的当刻，在小地图边缘和屏幕边缘各闪一个短箭头，指示方位（八方位），持续 3 秒，不弹窗、不暂停。普通出怪不提示。小波提示不显示合法落点范围、不提前于开门时刻、不预报下一次门位置。大波保持文字提示「某方向有大波敌人袭来」。

### 4.2 《游戏模式与关卡》第 5 节「生存模式」补充：生存界面基础信息

> **波次进度（生存）**：顶部显示「阶段 N/总数」与当前阶段第几次小波；最后一次小波清完后显示「大波将至」。不显示秒数，不显示方向（待 §6-9）。大波开启当刻显示方向并伴随号角。休整期显示「休整 xx 秒」，剩余 15 秒时提示「休整即将结束，请让前线工人撤回」。
>
> **失败页**：主城被毁时显示：开始时间、各次开门的方向与时刻、第一座被毁建筑、主城受损曲线、英雄是否在场、当时资源、最薄防线所在位置。提供「同图重来」和「返回菜单」。
>
> **胜利页**：用时、城市变化、核心卡、损失、远征贡献、勋章、再来一局。

### 4.3 《地图与资源点》第 6 节补充：营地发现与标记

> **营地可见性（原型）**：出生时自动显示距出生点最近的一个营地（方位、距离、守卫点数、奖励类型、预计往返时间）；其他营地进入任一己方单位或建筑视野后永久显示标记，并带上同样的信息。清场后标记变为「待领」，领奖后变灰。夜间营地有微光，白天无特殊标识。标记不揭示传送门位置。

### 4.4 《建造与修理》补充：休整的施工窗口与撤回提示

> **休整即安全施工窗口**：大波清完到休整结束之间不会新刷怪，前线开工的塔/墙/矿场不会遭遇新出现的敌人。已在场的敌人不被清除，开工前仍应确认周边是否有残敌。休整剩余 15 秒提示一次；休整结束后仍在前线施工的工人会随工地受到出怪威胁，已确定的「施工中无敌、工地被毁则工人死亡」规则不变。
>
> **召集失败的反馈**：全忙时提示「附近开拓者都在忙」，并显示空闲工人的数量与位置、最近一个会空出来的工人剩余时间。（队列方案见 P07，待裁决。）

### 4.5 《城镇经营》补充：资源面板优先级与反馈

> **资源栏**：顶栏固定显示金币净收入（+X/分，含税收、商店、维持费），钢铁、魔晶、能源（剩余/总）、人口（空闲/容量/被占用）。金币超过「可预见采购」的 3 倍时，金币数字改为较淡色，不再闪动，避免在宽裕阶段占用注意力；钢铁、能源和人口容量的变化用更强的提示。
>
> **战报**：每次大波后合并为一块：击杀、损失、新招装备兵承伤、新商圈净增、营地材料去向、「城镇贡献」一行（军属大院多招 N、药水兵承伤 X、矿山哨所挡下 Y）；不弹成三个窗口。
>
> **图鉴奖励**：发现 5/10/15 个组合各给「一点小奖励」未定义；建议改为外观奖励（主城装饰、门楼灯饰、称号），不给数值，避免绕过卡池与经济平衡。

### 4.6 《出怪系统》补充：敌人首次出现提示

> **首次遭遇提示**：每种敌人第一次出现时，屏幕下方给一行提示（可关闭），并记入图鉴：「破咒小子：魔法免疫，请用物理」「攀墙鬼：翻越城墙，无视墙」「孢囊怪：死亡爆炸并分裂」「野猪骑手：高速冲锋」「投矛绿皮：远程，可打后排」「巨怪：2000 血，建议控场」「孢巢怪：召唤」。魔免敌人头顶始终显示明显标记。这些提示不预知出现时间。

### 4.7 《随机增益》补充：选卡面板

> 选卡面板不暂停世界，可拖动；每个选项显示：效果一句话、当前能否立刻生效（待建/需士兵则标明）、与已拥有卡的关联提示（「与穿云箭相关」）、升级前后变化。已选未领的卡在顶栏有小角标，不会因休整结束而消失。若在大波开启时仍未领，保持待领，不重抽。

### 4.8 《古塞奇尤》/《开拓者》补充：英雄状态与召回

> 屏幕角常驻英雄状态条：驻守 / 外出（距家 N 米）/ 阵亡（复活倒计时，需 10000 金）；英雄升级时有闪光与数字（+40 血、+3 攻、回满）。「召回」按钮让英雄与已选中的外出队伍走回主城，不瞬移；召回中的单位仍可被攻击。

### 4.9 《游戏模式与关卡》第 4 节补充：战役首关教学检查表（仅清单，不改剧情）

> 首个战役应保证玩家至少亲手完成：放置并取消一次建造；读懂小地图方向提示一次；点一次修理并看到工人光圈；用攻击移动指挥英雄一次；选一次卡（预设 3 选 1，无风险）；用一次批量维修；读一次战报。完成后给出「下一关」的一句话悬念。以上不要求强制，全部可跳过。

### 4.10 其他应落文但目前缺失的条目

- 生存失败时是否有检查点（战役有回溯；生存仅一条命）：建议写明「生存不设检查点，失败即结算；可读已存的手动存档（若提供）」。
- 随机增益「没有跳过」的例外：若某手所有可见选项都当前无效，是否允许「保留待用」？建议保持无跳过，但允许先选「等价于最弱但无害」的选项（由内容配置保证每手至少一项当前有效，而非新增跳过）。
- 凯旋 60 秒与休整 90 秒的时钟叠加关系（前者结束早于后者）：应写明，避免凯旋在大波里被再次触发。

## 5. 玩家验证计划

沿用既定样本：至少 6 位首次玩家、3 位熟练复玩者，只作发现问题，不作统计证明。每局录屏 + 日志 + 事后访谈。

### 5.1 每局必须记录的日志

1. **时间线事件**（秒）：首座木屋/箭塔/兵营完成；首个组合；首个小波开门与英雄首次移动；Lv2/3/…升级时刻；每次大波开启/清场/休整结束；每次选卡的时刻与所选；出发/返回远征；每次英雄阵亡。
2. **资源曲线**：每 60 秒记录金币、钢铁、魔晶、能源剩余、人口容量/空闲/占用；金币超过「近 3 分钟采购总额」3 倍的累计时长（金币是否构成瓶颈）。
3. **操作负担**：召集失败次数与连续重试次数；单局内修理点击次数；休整内输入次数与间隔；连续 30 秒无输入的次数；暂停次数。
4. **战斗可读性**：每次开门到第一次玩家反应的延迟；每次被毁建筑的原因（谁、哪个方向、多久之前开的门）；诱饵墙（孤立外围建筑）数量与存活时间。
5. **英雄与远征**：英雄在家时间占比；每次外出的目的、队伍、收益、期间家中的损失。
6. **卡牌**：选前自述理由（思维外放）；选后 3 分钟内是否有位置变化；每张卡的实际触发次数。
7. **外层动机**：结束后「还想再来一局吗（1–5）」「想怎么玩下一局」「这一局最想改的一件事」。

### 5.2 每条提案的观察与否决信号

下表的数字是**发现问题的阈值**，不是统计显著性。

| 提案 | 观察什么 | 有效信号 | 否决信号 |
|---|---|---|---|
| P01 营地线索 | 出发时间、队伍、守家损失、奖励用途 | ≥3/6 在第一阶段有计划地出发或有理由地不出发；返回后收益被用于具体采购 | ≥5/6 立刻单人出发早亡；或 ≥5/6 完全无视；或第一次大波被碾平（资源提前过多） |
| P02 小波方向 | 开门→首次英雄/兵调度的延迟 | 有提示时调度更早且合理，无「预警」抱怨 | 玩家说「像预警」；或提示对行为无任何影响 |
| P03 阶段条/休整 | 玩家是否能说出「大波什么时候来」；休整末撤回前线工人的比率 | ≥4/6 能解释当前阶段；休整结束时前线工人损失下降 | 玩家说「信息太多」；或「大波将至」被视为预警 |

| P06 遗物 | 遗物营地访问率；因遗物改变英雄/兵行为 | 遗物营地被访问明显多于非遗物营地且有理由 | 无人关心；或「必须拿」导致路线单一 |
| P07 待派工 | 召集失败次数/局 | 仅统计：先看现状 | 平均 < 5 次/局则不采纳；采纳后出现「占坑不开工」滥用则撤回 |
| P08 Lv2 战斗卡 | 4:00–8:45 玩家的「无事可做」自述 | 仅当 ≥3/6 在该时段无事可做才启用 | 启用后第 1–2 阶段压力被明显抹平 |
| P09 删金币卡 | 现金/钢/人口曲线；「钱是否是瓶颈」自述 | 玩家后半局不再提「钱不够」 | ≥3/6 觉得钱是瓶颈：说明案头现金宽裕被高估，应复查 |

| P15 召回/状态条 | 召回使用率；英雄外出时间 | 英雄出门有明确原因；召回不被滥用 | 召回成为无成本规避；或没人注意状态条 |

### 5.3 针对核心风险的专项测试

1. **诱饵墙**：设定同一地图、同一波次，一组被告知可自由布局，另一组被要求不放孤立外围墙；统计大波被拖延时间与塔击杀占比。若 ≥2/6 自发使用并显著拖死大波，应另提方案（比如孤立建筑权重或距离限制），**而不是**偷偷改目标选择规则。
2. **科技路线远征**：只测科技路线的 3 位玩家，记录是否出门、出门理由、与建矿的取舍；若 0/3 出门，P01/P06 需要加强，否则营地对科技路线是死内容。
3. **英雄 vs 兵**：英雄在家时间 >80% 的玩家占比；若所有人都是如此，说明远征的奖励/成长理由不足。
4. **金币过剩**：记录「金币未花超过 3 倍采购」时长占比；若 ≥50% 的时间如此且玩家说「钱不是问题」，则 P09 及 4.5 的资源栏提示成立；若玩家感到「没有消费点」则优先选择材料/位置/英雄维度的内容，而不是加金币消耗。
5. **前十分钟情绪**：每 2 分钟让玩家自评 1–5「有趣/无聊」。【假设】0–3 分钟较高、4–7 分钟较低；若 4–7 分钟 ≥3/6 报 ≤2，则优先 P01/P08。

## 6. 需要用户裁决的取舍

按优先级排列。每项都给出我的倾向（【假设】），但不替用户决定。

1. **小波是否有「开门当刻」方向提示（P02）。**不裁决则第四轮样例的英雄回援前提不成立。倾向：给（较弱、无弹窗），保持无提前预警。
2. **营地发现规则与开局线索（P01）。**出生时揭示 1 个营地是否可以？它不是预警，却会改变开局节奏。倾向：先试，作为可开关的试玩配置。
3. **营地遗物是否取代任务系统（P06）。**触及《任务系统》中已确定的「奖励是任务特殊物品、只能通过任务得到」。倾向：合并；若不愿改，则保持任务系统仅在 S02 发一次，并让该次事件固定为「去某营地取遗物」。
4. **永久删除一批纯金币增益与战时萧条（P09）。**包括余粮生息、高利贷、清场奖金金币部分、闲时维修、寻宝人、战时萧条、税收递减候选。倾向：删除，但保留艺术/文字归档。
5. **建造/维修待派工队列（P07）。**触及设计提案「不排队」；先用数据决定。倾向：先统计，不开发。
6. **Lv2 首次奖励是否可含战斗卡（P08）。**触及暂定「仅经济类」且影响战斗数值。倾向：默认不开，当 4–8 分钟谷底得到试玩确认再说。
7. **战役首关的门位置是否可固定/脚本化。**「传送门位置纯随机」是否仅指生存？倾向：仅指生存；战役由作者脚本控制。
8. **「再来一局」范围：首版只做勋章（P10）、种子（P11）、复盘（P04）。**难度档（P13）、卡池解锁（P12）、局长选项（P18）暂缓。若用户希望首版就有难度档，需先说明验证成本：每档要重跑一遍联账。
9. **阶段条是否可显示「大波倒计时秒数」（P03）。**倾向：只给计数；秒数留待用户判定它是否属于「预警」。
10. **局长选项（P18：3 大波短局 vs 6 大波标准局）。**一局约 50 分钟是复玩摩擦，但 S01 内部短测的数据并未闭合，且用户已把 S01 定为内部测试。倾向：暂缓，不进菜单。
11. **英雄主动技（P16）。**默认不加；触发条件见 3.2。

### 6.1 我没有验证的假设（请勿当结论使用）

- 前十分钟的「平稳」来自第三轮合成模型；真实地图上随机门可能让第一小波更险或更松。
- 「2C 钢 ≈ 一座矿 3–6 分钟」依赖「近处仍有空矿点」；若真实地图上近处铁矿簇只有 1–2 点，远征钢的价值会上升。
- 英雄单独清营地「十几秒死亡」是用文档属性做的粗估，没有二维战斗验证。
- 28.7 万现金是单条合成路线的终局值；真人玩家可能花得更猛或更保守。
- 诱饵墙的有效性依赖敌人真实寻路、塔射程与墙的布局，案头无法定论。
- 所有「≥3/6」之类的阈值是发现问题的启发式，不是统计。
