# 第一轮 · 玩法策划独立审计

日期：2026-10-08。职责：评估决策、节奏、经营与战斗联动及开发范围；不代替两位数值策划确定最终价格。本轮依据现行项目总览、核心循环、模式、系统文档及关键经营/军事对象文档，不以归档为依据。所有体验评分与时长为设计预测，尚未完成真人试玩。

## 1. 体验判断

项目最有辨识度的体验是：把一个落脚营地经营成会赚钱的城市，把街区收益变成有自己流派的防线，再带英雄与少量机动军队夺取新的矿区。城镇布局、魔法科技双线与大波后的凯旋，能形成可见的成长。

目前不能直接判断游戏已经有趣。现行文档包含很多内容，但缺少一局内“何时需要做什么决定、做完后看到什么结果”的安排。首要问题不是继续增加塔和店，而是让已有机制产生明确取舍，并让玩家有时间感受结果。

必须保留用户方向：经营与防守并重；普通出怪、小波、大波三层；一般 2–4 次小波后一次大波；小波后照常普通出怪；仅大波清完后休整 1–2 分钟，最终大波直接胜利；魔法与科技双线；现有能源不足不让建筑停摆。本文不把候选修改伪装成用户已确定规则。

## 2. 高优先级问题与处理

| 问题 | 文档依据与体验后果 | 建议 |
|---|---|---|
| 发展时间与战斗终点没有统一 | 城镇 Lv6 估计 60–70 分钟，科技 3 本在 40–50 分钟；总大波次数与总局长未定。后期内容可能刚解锁就结束，或前期重复过久 | 先建立一套完整标准生存配置，并给后期新内容至少两个完整进攻周期的使用窗口；不要只压缩总时长而保留旧城镇阈值 |
| 同种经营数字可能变成必做清单 | 10 种店、19 组合、35 增益，加上住宅与科技研究；多建新种店还奖励繁荣，容易出现每局都按同一清单造一遍 | 一局选 2–3 个街区重点，而非要求凑全店种。建筑总目录保留，通过收益饱和与布局条件分化选择；首个试玩版本只实现少量代表机制 |
| 招募加成被线性淘汰 | 铁匠护甲 +1 很弱，药水、护盾又按固定排序覆盖；专卖店文档明确旧铁匠仅剩生意 | 保留每兵最多一项，但优先采用生产建筑可选“新兵装备”方案，分别适合持续承伤、爆发受伤、出征首战；取消自动“永远最好”排序属于规则调整候选，需主策评审后明确标注；至少避免在新建筑描述里承诺严格上位替代 |
| 商业收官奖励可能只有假星级 | 百货公司给附近店客单 ×1.25，但全街已到居民 40 金消费池时总收入不变；显示升星可能误导 | 星级由真实净收入决定；百货覆盖新住宅比挤在饱和街区好。预览同时显示“街区净增收入”，必须允许 +0，并说明顾客已饱和；不另开消费池绕过通胀约束 |
| 经营与战斗可能只是两张表 | 军属、铁匠、塔下驻军等有联动，但多数店只增金币 | 首版强调三种可看见的联动：铁匠改变新兵耐久、矿山哨所保护新增钢铁来源、凯旋给修复与新街区投资空间；战报显示这些结果。优先实现已有机制，不新增居民需求链 |
| 地图尺度与救援窗口不匹配 | 2048 米世界、3 米/秒步兵；门户离最近建筑 120–250 米，远矿在 500 米外；从主城到远矿可能超过 160 秒，而普通小店数只绿皮很快拆掉 | 门户仍从合法位置纯随机选，不暗改轮换；先按实际路径验算敌人抵达时间，并确保小波方向与遇袭定位可读。远矿扩张前预览往返时间及建议守军；传送阵仍按原路线后期解锁，不能作为前期救援的默认解法 |
| “最近建筑”可能被廉价诱饵破解 | 敌人锁最近建筑，拆后找下一座；外围铺孤立墙段可能花少钱把大波拖走 | 作为必要专项测试：测量诱饵经济、偏航与拖延。首轮保留已定选目标原则；如果廉价散墙成为通解，再讨论建筑目标权重或限制，不偷偷取消用户既定规则 |
| 大波之后仍可能忙得喘不过气 | 1–2 分钟休整只有一位工人修每建筑，修理主动触发，不设队列；多条防线逐一点击会耗尽休整 | 首先给受损建筑列表、点击定位、维修总费用/剩余施工时间、空闲工人指示，减少找目标；批量分配只派空闲工人、每工地仍 1 人，属于交互候选；不直接加入队列或免费自动修理 |
| 卡牌很多，但流派形成慢 | 大波才给战斗卡，城镇额外卡暂只经济；多数流派需要 3–4 卡 | 三选一至少一项当前可用战斗卡，未解锁内容不入池；保留未满级卡 ×1.3 既定权重，另做少量同流派相关加权。目标第三次大波前看见有辨识度的两卡协同，不能保证每局指定三卡必出 |
| 普通怪可能淹没小波身份 | 三层只规定大小，计时与组合均未定 | 普通出怪承担巡视和局部消耗，小波检验一种弱点，大波检验总体配置。小波采用清晰主题而非单纯数量上涨；大波期间新增普通出怪是否停止由数值方案统一，避免临时叠加不可解释的峰值 |
| 任务数量与当前方向矛盾 | 任务每 30–40 分钟一次，却预计一局拿 4–8 件 | 标准生存局先按 1–2 次可选事件规划，不依赖任务才能通关。玩家无视或失败没有惩罚；更长模式再按实际局长计算数量 |

## 3. 一局的决策骨架

建议标准生存配置采用 6 次大波作为首个验算入口，目标总长约 40–55 分钟，而不是既定时长。若两位数值策划证明科技与资源在此时间不可达，先调整提案门槛/研究节奏或选更长配置；不要让同一个配置同时引用旧 60–70 分钟解锁表。每轮 2–4 次小波，在编辑器明确配置，首次体验用固定构成，随机种子影响地图与合法门户位置。

| 周期 | 玩家主要问题 | 推荐敌人主题 | 经营奖励与改变 |
|---|---|---|---|
| 第一大波前 | 先补住宅收入，还是加塔并依靠英雄撑住？ | 以普通绿皮为主，第一次小波单向，给玩家理解射程和墙的时间 | 小村落与第一家店能看到真实收入变化；大波后第一次战斗增益 |
| 第二周期 | 机动民兵留家还是带英雄夺营地？ | 弓手制造前排压力；不同时引入多种新特殊敌人 | 拿到第一笔主动获取的魔晶；发展首个工业/军事街区 |
| 第三周期 | 科技范围伤害，还是魔法控制？ | 孢囊/密集群主题，允许范围流派展示 | 至少一侧 2 本可用；第一个两卡协同，应改变布防或打法 |
| 第四周期 | 守窄口还是接更远的矿？ | 铁皮绿皮让物理护甲差异可见，少量而非全波硬克制 | 第二能源来源或新铁矿，与前哨防线形成一次可解释的投资 |
| 第五周期 | 将资源集中主防线还是两面布防？ | 魔免/攀墙中选一种主题，再加入另一种作为小规模试探；不要求新手同时破解二者 | 主路线 3 本应已经可用；混搭或进一步经营是可选投资 |
| 最终大波 | 用自己形成的流派完成最后考验 | 组合已见过的敌人，明确一个巨怪目标；不在最终波首次出现未知机制 | 战斗后马上胜利，显示城市变化、核心卡协同、损失与远征贡献 |

时间控制应以敌人实际抵达/战斗/清场与大波后休整共同验算，不把 120–250 米行军当作零时间。大波残留、分裂和召唤的归属由数值战斗策划明确定义，并允许界面定位剩余大波敌人，避免清场被一只迷路单位拖住。

休整建议首轮用 90 秒统一值，属于用户 1–2 分钟范围内的提案。每次休整只提示一个推荐目标，例如“修复东门”“新街区可覆盖 40 人”“本阶段可建火炮塔”；玩家仍自由选择。增益、小报、客商反馈在同一处呈现，避免连续三个模态窗口。城镇在交战中升级只给简短横幅，选择延后到大波后已有设计可沿用；是否暂停世界供选卡必须明确定义，不能凭空假定。

## 4. 可直接用于试玩的事件脚本

**脚本 A：第一轮经营兑现。**木屋完工→居民入住→第三住宅出现“小村落”→放面包房时预览真实每分钟增益→第一小波到箭塔前→英雄支援解决→仍有普通怪出没→大波方向提示→玩家移民兵→清完进入 90 秒休整→选第一张战斗卡→修受损塔或扩店。观察玩家是否能说明“为什么现在不继续盖房”。首次普通进攻实际抵达须晚于基础防守完成，不默认全图安静四分钟。

**脚本 B：出去拿魔法，家里仍能守。**第二周期玩家看到一个可达营地与奖励→界面显示距家/预计返回时间→英雄带 2–3 名民兵出征，基地留塔→普通怪袭外围，玩家决定返程或相信防线→清营地获得魔晶和英雄经验→回基地建魔法线或保留晶体。预测乐趣来自取舍；若玩家只等大波刷资源更好，说明探索回报/风险需数值调整。

**脚本 C：流派兑现。**已有穿云箭/火力卡的玩家遇密集小波，箭塔表现明显提升；已有碎冰/凝滞玩家看到敌人拆墙速度降低。大波战报用“穿透额外命中数/减速争取的防线时间”等可归因指标替代只显示总伤害。两种打法应都能通关，采用不同建筑布局。

**脚本 D：远矿可损失但能挽回。**第四周期新矿明确增加钢铁或能源→玩家建一组前哨→随机门户从该矿合法范围出现→就地守军撑住，或矿被拆造成扩建暂停→现有塔与灯继续工作→休整中恢复矿或放弃远矿。若所有随机入口都只能看着矿死，应先调地图路径/守军成本/抵达窗口，不宣称这叫高难度。

## 5. 增删与实施顺序

立即增加的内容是决策反馈：收入净增预览、受损列表、在场大波残敌定位、当前流派摘要、实际路径时间；不增加资源种类或复杂居民需求。

保留完整设计目录与已做美术，暂缓进入第一个可玩验证版本的有：海上扩张、运输与平台施工链、核弹、曙光号及大量高级兵种、19 个组合全量。不是从产品永久删除；首轮先验证一张主大陆地图、六轮完整生存、两条到 3 本的成长线、每路线有明确单体/范围/控制角色、3–4 种店、5 个可见组合、能够组成 3 种不同打法的增益子池。保留后续商业街到 Lv6 的总规划，但不要用尚未实现的内容支撑本版通关预算。

优先删除或修订文档中的冗余承诺：旧每 15 小波频率、旧基于 60 秒小波的局长、任务 4–8 件不符合稀少频率、百货无收入增长却升星、把护盾称为对所有兵都“最好”。只修订提案与矛盾，不私自改用户定值。

## 6. 趣味性验收，而不是保证有趣

建议至少 6 位非开发者首次试玩，加 3 位熟练玩家用同一配置不同种子复玩；样本只做发现问题，不能当统计证明。设计验收目标如下：

| 指标 | 试玩目标/否决信号 |
|---|---|
| 能解释取舍 | 第一大波后至少 4/6 首玩者能说清一次“发展还是守家”的选择；不能只回答按提示造建筑 |
| 经营并非摆设 | 至少 4/6 愿意主动改变一次街区布局，并看到净收入/军队变化；若只是机械堆木屋，经营改造失败 |
| 流派及时形成 | 第三大波结束前至少 4/6 能描述自己的两卡协同，并据此改布局/招兵；单纯数字卡不算协同 |
| 压力可回应 | 远矿损失玩家能指出原因与下一局改善方法；“随机门出现就死”超过两人即优先修复 |
| 休整真能整理 | 至少 4/6 能在一次休整中完成修复加一项自主投资；等待超过 30 秒无目标记为无聊事件，连续点墙维修记为负担事件 |
| 有可重复策略 | 熟练玩家使用至少三种不同的战斗/经营策略取得胜利，不依赖同一种诱饵墙或相同开局清单；这是初步可行性，不代表完全平衡 |
| 输了还想再试 | 独立询问是否愿意再玩与原因；出现“内容没用完但只想结束”或“从头盖一样房子太累”必须调整，而非继续加内容 |

记录峰值操作数、低谷无决策时长、资源结余、阶段解锁时间与每次损失原因。接受首轮被证明不好玩；下一轮按证据修改最影响体验的两三项，不以增加系统数量作为进步。

## 7. 提交主策的待决项

1. 确认第一套标准生存总时长和大波数，与城镇/双线成长同表校准。
2. 判定“招募装备由玩家选择”是否采纳；若不采纳，必须解释旧店在后期的作用。
3. 采纳真实净收益决定星级、低收益饱和提示与残敌定位。
4. 定义首版可玩切片和完整内容规划的关系，保留已确认内容在后续实现清单。
5. 以两卡协同、主动布局、可回应损失为趣味性门槛；计算平衡通过后仍必须真人试玩。

## 8. 与数值组对齐的最小边界

收到数值组的风险清单后，补充以下规则候选。它们不需要新增资源或需求系统，尚待主策裁定。

- **教学与标准局分开。**战斗组的 24–30 分钟、3 大波且每大波前 3 小波，可作为教学生存测试配置。它只验证开局、一次 2 本成长和初级两卡协同，不强迫 3 本、Lv6 商店、海上内容全部开放。上文六大波/40–55 分钟仅为完整标准局的另一个验算入口，不是覆盖教学配置的决定。
- **消费池先限真实支出，再分账。**凯旋建议在 60 秒内让居民消费池从 40 提案值提高到 80，而不是在每一家店分完后各乘 2。住户最终税收加店消费仍统一受该住户总加成 +100% 上限；不能重复扣同一住户的空间。街区星级只看最终分账后的真实收入。不实现翻倍消费池时，就必须将凯旋表述为客单翻倍并提示饱和，不承诺总收入翻倍。
- **城镇等级不降，达到新等级需真实在场繁荣。**仅首次跨线升级、发一次奖励；临时店拆掉后的繁荣立即扣除，累计建过不同店不能当作现存店种。这里沿用原文“现在有多少”，修正实现口径即可。若达到高等级后立即拆店却永久拥有科技门槛仍构成通解，再追加“新建/升本时当前繁荣达门槛”候选；它会收紧既定城镇等级门槛，不能暗中采用。
- **能源缺口不让现有建筑停机，也不允许新占用趁施工未结算重复下单。**建造/升级确认时预留能源，取消返还预留，建成转为正式占用。主动拆除发电建筑需要明确是否允许在负能源状态形成免费永久供给；建议负能源风险对话先提示净值与无法扩建，并专项测试“造发电→造塔→主动拆发电→留塔”收益。若成为通解，主策可采用“主动拆除/回收后必须保证剩余总产出不低于总占用，敌人摧毁不受此限”的最小防套利候选。它限制主动拆除，保留被毁不断电规则；不发明停电伤害或新资源。
- **不要把隐患都变成重规则。**若发电不可主动回收，长期占地和造价本身已限制循环；若营地奖励不够，先修探索回报，不做商店产魔晶；若满池店只为繁荣，预览明确收益低，玩家仍可为兵营功能/组合造它。
