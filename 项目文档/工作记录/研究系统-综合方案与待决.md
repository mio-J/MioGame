## 1. 起因与目标

用户的反馈：

1. 现在只有研究院的「箭矢升级」，其他研究基本没有。
2. 纯数值强化（+20% 攻击之类）「有点无聊」。
3. 想要「像文明那样非常复杂的研究方向」。
4. 之前给的树状分支 + 互斥弹药路线示例，「箭头只能影响两个塔，总感觉哪里还是不对」。
5. 允许改动底层结构，要「适合这个游戏的、有意思的」方案。
6. 一贯偏好：玩家操作量低；价格后定；没定的标待定。

**问题的本质**：研究的「主语」是某一座建筑（铁箭头 → 箭塔），而玩家脑子里的主语是「我这支军队能不能顶住下一批敌人」。主语对不上，研究再复杂也像给个别塔打补丁。

## 3. 最重要的共识与发现

### 3.1 五个方案独立得出同一个底层结构

不约而同做了「**标签层 + 统一修饰器**」：给塔、单位、敌人打标签，研究写成「对带某标签的一切生效」。一条研究因此覆盖十几种东西，新塔只要打标签就自动吃到旧研究。这直接回答「影响面太窄」。

评审给的补充：
- 词表要压小：伤害渠道 4 个 + 功能标签不超过 6 个；敌人特征直接读现有属性（护甲 ≥20、魔免、分裂体、远程、速度 ≥5、生命 ≥1000），不要另造。
- 每个研究悬停显示「**影响 N 种（已建 M 个）**」，是对「只影响两座塔」最便宜、最直接的回应。
- **研究、任务物品、随机事件、天气共用同一套修饰器**。「开拓者移速翻倍」就是一行数据，研究系统与你想要的随机道具是同一个引擎。

### 3.2 评审发现的现实问题

1. **代码里还没有塔、单位、敌人、波次**。`AlienFrontier` 目前只有地形、天气、相机、HUD、资源点和一个 `Actor` 基类。研究系统的钩子必须在写第一座塔时就内建进 Tower/Unit 基类，不能事后加。
2. **护甲公式代码与文档不一致**（我已核实）：
   - 文档（战斗与护甲规则）：受伤比例 = 30 ÷ (30 + 护甲)，20 甲受伤 60%。
   - 代码 `scripts/actors/actor.gd`：`1 / (1 + 0.06 × 护甲)`，20 甲受伤 45.5%。
   - 应在写战斗系统时对齐；负护甲那一半我还没核对。
3. **黎明只有约 36 秒**（`time_of_day.gd` 里 `DAWN_END=0.06`，每 10 分钟一次），所以「黎明免费整编」不可行。
4. **魔法线门槛基本到不了**：法师营地要古塞奇尤 Lv5，但她的经验只来自普通绿皮，而点数预算里普通绿皮占比很小。
5. **研究树耗尽后没有续航**：无尽模式后半段成长会空转。
6. **蚀（腐蚀）必须归为物理**：腐蚀塔、腐蚀无人机对破咒小子有效，不能被「元素 = 魔法」的规则吞掉。

## 4. 综合方案：「学说树 + 方针槽」

### 4.1 底层

1. **标签**：见 3.1。
2. **修饰器注册表**：研究、任务道具、事件、天气共用。封顶规则：同通道相加、跨通道相乘；增伤共池设上限（量级 +50%~+60%），腐蚀下限 −15 照旧。

### 4.2 玩家看到的

1. **学说树**：科技（研究院）、魔法（法师营地）各一棵，按本数分层。大多数节点的产物是**解锁一张方针卡**，或赋予标签 / 写一条联动，纯数值节点只占少数。
2. **方针槽**：数量有限，卡是全局规则。**取舍放在槽位，研究不互斥**：随时能研究、永不锁死、不会点错就废。「火箭弹 vs 穿甲弹」是同一个军事槽里的两张卡，玩家按遇到的敌人切换。
3. **灵感**：敌人**首次出现**让对应研究时间减半；吃亏也算进度。零操作。
4. **精通**：每张卡按战场计数升阶（规则的微升级，不是数值），解决树耗尽后的续航。
5. **融合研究**：需要科技、魔法两侧的前置，把两条线连起来。

### 4.3 槽位（草案）

| 槽 | 类型 | 来源 |
|---|---|---|
| 军事 | 怎么打 | 开局 1，研究院 3 本再 +1 |
| 经济 | 钱从哪来 | 开局 1 |
| 工程 | 怎么建 | 研究院建成 +1 |
| 魔法 | 魔法侧规则 | 法师营地建成 +1，3 本再 +1 |
| 融合 | 跨体系 | 两座科技建筑都建成 +1，都 3 本再 +1 |

槽位成长与「魔法看英雄等级、科技看人口」的现有门槛对齐。事件 / 随机道具也可以发放额外的槽位或卡。

### 4.4 卡的例子（数值只给方向，一律待定）

| 卡 | 侧 | 效果 | 覆盖 |
|---|---|---|---|
| 火箭弹 | 科技 | 命中点燃，持续灼烧（物理） | 箭塔、双重、多重、钢雨、火枪手、物理无人机 |
| 穿甲弹 | 科技 | 无视一定量**正护甲** | 弹道与轰击类 |
| 破片弹 | 科技 | 命中溅射 | 同上 |
| 墙体守势 | 科技 | 倒刺反伤，或垛口提高墙邻近塔的射程 | 城墙、城门及邻近的塔 |
| 战地工程 | 科技 | 开拓者建造 / 修理更快，空闲时自动维修 | 开拓者、城防 |
| 征召令 | 科技 | 士兵阵亡后原价自动补员（默认关，金币低于保留线暂停） | 兵营产出 |
| 导电 | 魔法 | 连锁多跳一次 | 古塞奇尤、风暴尖塔、雷环塔 |
| 寒潮法令 | 魔法 | 被控制（减速、定身）的敌人受到的伤害增加 | 凝霜、缚灵、腐蚀… |
| 愈合咒 | 魔法 | 士兵脱战后自动回血 | 全部士兵（不含圣骑士） |
| 共振 | 融合 | 被魔法命中的敌人短时间内受物理伤害增加 | 魔法塔 × 物理塔 |
| 魔晶炉 | 融合 | 把能源盈余转化为魔晶 | 太阳能、油井、海上石油平台 |

### 4.5 与敌人的对应（保证选择有意义）

| 敌人 | 对策方向 |
|---|---|
| 铁皮绿皮（物理减半） | 穿甲弹、腐蚀；魔法天然无视 |
| 孢囊怪（分裂） | 破片弹、导电、范围魔法 |
| 攀墙鬼（翻墙） | 墙体守势、墙后留守 |
| 破咒小子（魔免） | 物理路线；魔免本身不被研究破除 |
| 投矛绿皮（限次爆发） | 护盾、墙体守势（垛口） |
| 巨怪（重型） | 寒潮法令 + 控制链、多塔叠加 |

### 4.6 砍掉的东西与原因

| 方案里的点子 | 为什么没采纳 |
|---|---|
| 敌人适应（用得越偏，克星越多） | 评审认为有「被针对感」，且复杂，可以以后再试 |
| 按型号逐个改装的模组 | 界面与结算成本高，放后续 |
| 让魔免失效的研究 | 改写已确定规则 |
| 黎明免费整编窗口 | 黎明只有约 36 秒 |
| 补齐旧兵升本加成 | 改写已确定规则 |
| 战场档案 4 级、冷门渠道加成等 | 机制过多，首版只留「首次出现 → 灵感」 |

### 4.7 联动

- **出怪系统**：灵感读「敌人首次出现」，新敌人自动带档案提示，不用改研究表。
- **事件 + 随机道具**：同一套修饰器。事件奖励可以是三选一的永久道具，也可以是额外卡 / 槽位。
- **预警（后面再定）**：可作为一张魔法侧的卡，由研究解锁，不是默认能力。
